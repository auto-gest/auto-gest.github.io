点按

最基本的动作：AutoGest 精准点击你在屏幕上选的位置。

  1. 点“添加动作”，选点按
  2. 点“添加位置”
  3. 打开应用，把准星拖到要点的位置
  4. 点 OK 保存坐标
  5. 回到 AutoGest，坐标已填好
  6. 点试运行，然后打开应用

▶ AutoGest 精准点击所选位置

小提示
  • 坐标会按屏幕尺寸换算，换到屏幕不同的手机上也能点准。
  • 在通用设置里设置步骤间的停顿和点击的小偏移，操作更像真人。
  • 按钮位置会变？用点按图片、点按文字(OCR)或点按文字让 AutoGest 先找到它。

连续点按

以每秒 1 到 20 次的速度连续点击同一位置，适合需要快速连点的游戏。

  1. 点“添加动作”，选连续点按
  2. 点“添加位置”
  3. 打开应用，把准星放在按钮上
  4. 点 OK 保存坐标
  5. 回到 AutoGest，减少点击次数
  6. 点试运行，然后打开应用

▶ AutoGest 点击 30 次，每秒 10 次

小提示
  • 可以按次数、按时间停止，或一直点到你按停止。
  • 每秒超过 10 次比人手还快，有些应用可能视为异常。
  • 打开自然节奏，点击间隔会像真手指一样略有变化。

长按

按住一个位置，时长由你决定——用于长按确认按钮、上下文菜单、拖动选择。

  1. 点“添加动作”，选长按
  2. 点“添加位置”
  3. 打开应用，把准星放在按钮上
  4. 点 OK 保存坐标
  5. 回到 AutoGest，选择长按时长
  6. 点试运行，然后打开应用

▶ AutoGest 长按按钮 2 秒，解锁成功

小提示
  • 对于“长按确认”的按钮，时长设得比应用要求的稍长一点。

滑动

手指从起点拖到终点——滑动解锁、拖动滑块、翻页。

  1. 点“添加动作”，选滑动
  2. 选择起点
  3. 返回，选择终点
  4. 返回，选择滑动时长
  5. 点试运行，然后打开应用

▶ AutoGest 从起点滑到终点

小提示
  • 时长短是快速滑动，时长长是慢慢拖动（拖放、滑块）。

滚动

在屏幕中间滑一下，把列表向上、下、左、右滚动——无需选坐标。

  1. 点“添加动作”，选滚动
  2. 选择方向和时长
  3. 点试运行，然后打开应用

▶ AutoGest 在屏幕中间滑动来滚动

小提示
  • 搭配重复直到，可以一直滚动到出现你要找的内容。

粘贴文本

点一下输入框，把准备好的整段文字填进去——又快，字符也不会出错。

  1. 点“添加动作”，选粘贴文本
  2. 点“添加位置”，对准输入框
  3. 返回，输入要粘贴的内容
  4. 点试运行，然后打开应用

▶ AutoGest 把整段文字粘贴进输入框

小提示
  • 用 || 分隔多段文字，每次运行 AutoGest 会随机选一段。
  • 用插入变量插入变量，可粘贴本次运行中先前读到的值。
  • 应用禁止粘贴？用逐键输入像打字一样逐个按键。

逐键输入 PRO

录下你在键盘上按的每个键；运行时 AutoGest 按你的节奏按同样的键。

  1. 点“添加动作”，选逐键输入
  2. 点按键录制框，在键盘上输入
  3. 点“完成”保存按键
  4. 选择要输入的框（可选）
  5. 返回，点试运行，然后打开应用

▶ AutoGest 点输入框，再逐个重放按键

小提示
  • AutoGest 按键盘位置点按，录制和运行时请使用同一个键盘（以及同类输入框）。
  • 输入后 AutoGest 会检查输入框，文字不符就报错并停止输入。
  • 不需要逐键输入？把卡片切换为粘贴文本。

↑ 返回动作列表

等待

在下一步前停一下——等画面加载、动画结束或计时器走完。

  1. 点“添加动作”，选等待
  2. 输入等待时间（毫秒）
  3. 添加一个 点按 步骤来看停顿
  4. 在“通用设置”里把脚本重复 2 次
  5. 点试运行，然后打开应用

▶ 两次点击相隔 3 秒，再加步骤间的停顿

小提示
  • 每一步本来就会随机停顿一小会儿（在通用设置里设置）；只有需要更久时才加等待。
  • 在等某样东西出现？等待图片、等待文字(OCR)或等待颜色一出现就继续。

↑ 返回动作列表

等待图片 PRO

不点击，等到屏幕上出现（或消失）某张图片，然后再执行后面的步骤。

  1. 点“添加动作”，选等待图片
  2. 点“选择图片”，选“从屏幕裁剪”
  3. 打开画面，点截取，框住图片
  4. 返回，在图片出现的位置添加 点按
  5. 返回，点试运行，然后打开应用

▶ AutoGest 等礼物盒出现后才执行 点按

小提示
  • 把图片裁得紧贴目标，不要包含会变化的背景。
  • 如果图片每次略有不同，调低最低匹配度。

↑ 返回动作列表

等待颜色 PRO

盯住一个点，直到它变成指定颜色（或改变颜色）——比如红绿灯变绿、按钮变为可用。

  1. 点“添加动作”，选等待颜色
  2. 点“添加位置”，对准要等颜色的位置
  3. 返回：AutoGest 已读出该处颜色
  4. 在“出发”上添加点按步骤
  5. 返回，点试运行，然后打开应用

▶ AutoGest 等到绿灯才点“出发”

小提示
  • 在屏幕显示目标颜色时选点，AutoGest 会帮你读出颜色。
  • 只看屏幕图像，所以游戏里也能用。

↑ 返回动作列表

点按图片 PRO

在屏幕上找到一张图片并点击，无论它在哪——最适合会移动的按钮。

  1. 点“添加动作”，选点按图片
  2. 点“选择图片”，选“从屏幕裁剪”
  3. 打开有图片的画面，点截取
  4. 把框贴紧图片，点 OK
  5. 返回，点试运行，然后打开应用

▶ AutoGest 等礼物盒出现后点击它

小提示
  • AutoGest 看的是屏幕图像而不是应用结构，所以游戏里也能用。
  • 只裁按钮本身，不要带周围的背景。

↑ 返回动作列表

点按文字(OCR) PRO

用手机本地的文字识别（OCR）读取截图里的文字并点击——即使是自己绘制文字的游戏也行。

  1. 点“添加动作”，选点按文字(OCR)
  2. 输入按钮上的文字
  3. 点试运行，然后打开应用

▶ AutoGest 读取屏幕图像（游戏里也行）并点击文字

小提示
  • 中文请选“中文”字符集；英文等用 Latin 即可。
  • 缩小搜索区域，读得更快更准。
  • 识别在手机本地完成，不会发送到任何地方。

↑ 返回动作列表

等待文字(OCR) PRO

不点击，等到屏幕图像上出现（或消失）某段文字。

  1. 点“添加动作”，选等待文字(OCR)
  2. 输入要等待的文字
  3. 在“起跑”上添加点按步骤
  4. 返回，点试运行，然后打开应用

▶ AutoGest 等到“出发”才点“起跑”

小提示
  • 适合“预备…出发！”“胜利”或倒计时结束这类游戏画面。
  • 选定区域可以更快等到，也不会误认别处的相同文字。

↑ 返回动作列表

识别文字(OCR) PRO

读取屏幕图像某个区域里的文字，存到变量供后面的步骤使用。

  1. 点“添加动作”，选识别文字(OCR)
  2. 点“选择区域”，打开画面，点截取
  3. 框住验证码，点 OK
  4. 返回，选“只取数字”和要保存的变量
  5. 在输入框添加粘贴文本，插入变量
  6. 在“确认”上添加点按步骤
  7. 点试运行，然后打开应用

▶ AutoGest 从图像读出验证码并填入

小提示
  • 选“只取数字”只保留数字——分数、价格或验证码。
  • 变量可用于粘贴文字，或在如果…则区块里比较。

点按文字

输入按钮上显示的文字；运行时 AutoGest 在屏幕上找到这段文字并点击。

  1. 点“添加动作”，选点按文字
  2. 输入按钮上显示的文字
  3. 点试运行，然后打开应用

▶ 无论按钮在哪里，AutoGest 都能找到文字并点击

小提示
  • 它读取应用结构，所以对自己绘制文字的游戏无效——这时请用点按文字(OCR)。
  • 不区分大小写，只要包含你输入的文字即可。

点按节点 PRO

截取屏幕、点一个元素，AutoGest 就会记住如何再次找到它——只有图标的按钮也可以。

  1. 点“添加动作”，选点按节点
  2. 点“选取节点”，打开应用，点截取
  3. 点要按的按钮，再点“选取节点”
  4. 返回，选择查找节点的方式
  5. 点试运行，然后打开应用

▶ AutoGest 找到爱心按钮并点击

小提示
  • text 或 content-desc 不变时就用它们查找；应用更新会变的 resource-id 尽量避免。
  • 删掉每次都变的部分（比如计数），下次也能找到。

↑ 返回动作列表

读取屏幕文字 PRO

选屏幕上的一个元素，不点击，把它的文字复制到变量。

  1. 点“添加动作”，选读取屏幕文字
  2. 点“选取节点”，打开应用，点截取
  3. 点验证码，再点“选取节点”
  4. 返回，选择要保存的变量
  5. 在输入框添加粘贴文本，插入变量
  6. 在“确认”上添加点按步骤
  7. 点试运行，然后打开应用

▶ AutoGest 复制验证码并填入

小提示
  • 适合获取一次性验证码、订单号或应用里显示的余额。
  • 它读取应用结构；游戏请用识别文字(OCR)。

等待并识别通知 PRO

等待包含你所选文字的通知，朗读出来，然后继续运行脚本。

  1. 点“添加动作”，选等待并识别通知
  2. 点“选取样本通知”，选一条通知
  3. 输入通知必须包含的文字
  4. 点“使用此样本”
  5. 在“确认订单”上添加点按步骤
  6. 返回，点试运行，然后打开应用
  7. 有顾客下单时…

▶ AutoGest 朗读通知后点确认

小提示
  • 选一条真实通知作样本，输入要等的文字；每次会变的部分（如订单号）会宽松匹配。
  • 只等通知的脚本可以在后台运行，屏幕关闭也行。
  • 通知内容只留在你的手机里，绝不写入日志。

如果… 就 PRO

条件成立时才执行某些步骤——条件可以是图片、颜色、文字、轮次或变量。

  1. 点“添加动作”，选如果… 就
  2. 选“文字”，输入要找的文字
  3. 关闭“否则”分支，点“完成”
  4. 在“则”分支添加：点按 关闭（✕）按钮
  5. 返回，点试运行，然后打开应用

▶ AutoGest 看到“广告”就点关闭

小提示
  • 打开“否则”分支，条件不成立时执行另一些步骤。
  • 区块只有一层；需要嵌套时，把逻辑拆到另一个脚本，再用调用脚本。

↑ 返回动作列表

重复直到 PRO

重复区块内的步骤，直到条件成立或达到设定的轮数。

  1. 点“添加动作”，选重复直到
  2. 按“文字”停止：输入结束时出现的文字
  3. 在循环里添加：点按“加载更多”
  4. 返回，点试运行，然后打开应用

▶ AutoGest 一直点“加载更多”，直到出现“没有更多新闻了”

小提示
  • 一定要设最大轮数，避免脚本因失误一直运行。

停止脚本 PRO

条件满足时结束整次运行——比如次数或体力用完时。

  1. 在“转动”上添加点按步骤
  2. 返回，添加停止脚本
  3. 出现“次数已用完”时停止
  4. 脚本无限重复
  5. 点试运行，然后打开应用

▶ 最后一次转完后，AutoGest 自动停止

小提示
  • 对无限循环来说，这是干净的结束方式。
  • 放在如果…则的分支里，可以不设条件直接停止。

进入下一轮 PRO

条件满足时跳过本轮剩下的步骤，开始下一轮。

  1. 在“下一条”上添加点按步骤
  2. 出现“赞助”时添加进入下一轮
  3. 在“点赞”上添加点按步骤
  4. 脚本重复 4 次
  5. 点试运行，然后打开应用

▶ AutoGest 给第 1、3 条点赞，跳过赞助内容

小提示
  • 浏览列表时用来跳过广告或不需要的项目。
  • 它会跳到同一脚本中最近的循环末尾。

↑ 返回动作列表

调用脚本 PRO

运行另一个脚本后再回来——复用你已经做好的步骤。

  1. 点“添加动作”，选调用脚本
  2. 点“选择脚本”，选要调用的脚本
  3. 选择调用次数
  4. 点试运行，然后打开应用

▶ AutoGest 运行“点按钮”3 次

小提示
  • 选择连续调用的次数。
  • 被调用的脚本按本脚本的节奏设置运行。
