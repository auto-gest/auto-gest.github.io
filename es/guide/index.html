Guía de uso

Cada acción tiene un vídeo corto grabado en un móvil real, con una app de ejemplo para que veas el resultado. Cada toque se ilumina para que sea fácil de seguir. Las acciones con la etiqueta PRO forman parte de AutoGest Pro.

Tocar

La acción más básica: AutoGest toca exactamente el punto que elegiste en la pantalla.

  1. Toca «Añadir acción» y elige Tocar
  2. Toca «Añadir punto»
  3. Abre la app y arrastra la mira hasta el punto
  4. Toca OK para guardar el punto
  5. De vuelta en AutoGest, el punto ya está puesto
  6. Toca Probar y abre la app

▶ AutoGest toca justo el punto elegido

Consejos
  • Los puntos se adaptan al tamaño de la pantalla, así que el script acierta también en un móvil con otra pantalla.
  • En Configuración general ajustas la pausa entre pasos y un pequeño desvío del toque, para que parezca una persona real.
  • ¿El botón cambia de sitio? Usa Tocar imagen, Tocar texto (OCR) o Tocar texto para que AutoGest lo busque primero.

Toques rápidos

Toca un punto una y otra vez, de 1 a 20 veces por segundo; ideal para juegos que piden tocar rápido.

  1. Toca «Añadir acción» y elige Toques rápidos
  2. Toca «Añadir punto»
  3. Abre la app y pon la mira sobre el botón
  4. Toca OK para guardar el punto
  5. De vuelta en AutoGest, baja el número de toques
  6. Toca Probar y abre la app

▶ AutoGest toca 30 veces, 10 toques por segundo

Consejos
  • Para tras un número de toques, tras un tiempo, o sigue hasta que pulses Detener.
  • Más de 10 toques por segundo supera a una mano humana; algunas apps pueden considerarlo inusual.
  • Activa el ritmo natural para que el intervalo entre toques varíe un poco, como un dedo real.

Mantener pulsado

Toca y mantén un punto el tiempo que elijas: botones de mantener para confirmar, menús contextuales, seleccionar arrastrando.

  1. Toca «Añadir acción» y elige Mantener pulsado
  2. Toca «Añadir punto»
  3. Abre la app y pon la mira sobre el botón
  4. Toca OK para guardar el punto
  5. De vuelta en AutoGest, elige cuánto mantener
  6. Toca Probar y abre la app

▶ AutoGest mantiene el botón 2 s y se desbloquea

Consejos
  • Para un botón de «mantener para confirmar», elige un tiempo algo mayor que el que pide la app.

Deslizar

Arrastra el dedo de un punto de inicio a un punto final: deslizar para desbloquear, mover un control, pasar páginas.

  1. Toca «Añadir acción» y elige Deslizar
  2. Elige el punto de inicio
  3. Vuelve y elige el punto final
  4. Vuelve y elige la duración del deslizamiento
  5. Toca Probar y abre la app

▶ AutoGest desliza del punto de inicio al final

Consejos
  • Una duración corta es un deslizamiento rápido; una larga, un arrastre lento (arrastrar y soltar, controles deslizantes).

Desplazar

Desplaza una lista hacia arriba, abajo, izquierda o derecha con un deslizamiento por el centro, sin elegir ningún punto.

  1. Toca «Añadir acción» y elige Desplazar
  2. Elige la dirección y la duración
  3. Toca Probar y abre la app

▶ AutoGest desliza por el centro para desplazarse

Consejos
  • Combínalo con Repetir hasta para desplazarte hasta que aparezca lo que buscas.

Pegar texto

Toca un campo de texto y rellénalo con todo el texto que preparaste: rápido y con cada tilde en su sitio.

  1. Toca «Añadir acción» y elige Pegar texto
  2. Toca «Añadir punto» y apunta al campo de texto
  3. Vuelve y escribe el texto que se pegará
  4. Toca Probar y abre la app

▶ AutoGest pega todo el texto en el campo

Consejos
  • Separa varios textos con || y AutoGest elige uno al azar en cada ejecución.
  • Inserta una variable con Insertar variable para pegar un valor leído antes en la ejecución.
  • ¿La app no deja pegar? Usa Escribir caracteres para pulsar cada tecla como al escribir.

Escribir caracteres PRO

Graba cada tecla que pulsas en el teclado; al ejecutar, AutoGest pulsa las mismas teclas con tu ritmo.

  1. Toca «Añadir acción» y elige Escribir caracteres
  2. Toca el cuadro de grabación y escribe en el teclado
  3. Toca «Listo» para guardar las teclas
  4. Elige el campo donde escribir (opcional)
  5. Vuelve, toca Probar y abre la app

▶ AutoGest toca el campo y repite cada tecla

Consejos
  • Usa el mismo teclado (y el mismo tipo de campo) al grabar y al ejecutar, porque AutoGest pulsa según la posición de las teclas.
  • Después de escribir, AutoGest revisa el campo; si el texto no coincide, el paso da error y deja de escribir.
  • ¿No hace falta pulsar cada tecla? Cambia la tarjeta a Pegar texto.

Esperar

Pausa antes del siguiente paso: deja que cargue una pantalla, termine una animación o acabe un temporizador.

  1. Toca «Añadir acción» y elige Esperar
  2. Escribe el tiempo de espera (ms)
  3. Añade un paso Tocar para ver la pausa
  4. Repite el script 2 veces en «Configuración general»
  5. Toca Probar y abre la app

▶ Los toques llegan con 3 s de diferencia, más la pausa entre pasos

Consejos
  • Cada paso ya espera una pausa corta al azar (ajústala en Configuración general); añade una espera solo si necesitas más.
  • ¿Esperas a que algo aparezca? Esperar imagen, Esperar texto (OCR) o Esperar color siguen en cuanto aparece.

Esperar imagen PRO

Espera hasta que una imagen aparezca (o desaparezca) en la pantalla, sin tocar; después siguen los demás pasos.

  1. Toca «Añadir acción» y elige Esperar imagen
  2. Toca «Elegir imagen» y elige «Recortar de la pantalla»
  3. Abre la pantalla, toca Capturar y enmarca la imagen
  4. Vuelve y añade un paso Tocar donde aparece la imagen
  5. Vuelve, toca Probar y abre la app

▶ AutoGest espera la caja de regalo y luego ejecuta el paso Tocar

Consejos
  • Recorta la imagen ajustada a lo que buscas, sin fondos que cambien.
  • Baja la coincidencia mínima si la imagen se ve un poco distinta cada vez.

Esperar color PRO

Vigila un punto hasta que tenga un color elegido (o cambie de color): una luz que se pone verde, un botón que se activa.

  1. Toca «Añadir acción» y elige Esperar color
  2. Toca «Añadir punto» y apunta al punto con el color
  3. Vuelve: AutoGest ya leyó el color de ese punto
  4. Añade un paso Tocar en «Avanzar»
  5. Vuelve, toca Probar y abre la app

▶ AutoGest espera la luz verde y luego toca «Avanzar»

Consejos
  • Elige el punto cuando la pantalla muestre el color que quieres: AutoGest lo lee por ti.
  • Funciona también en juegos, porque solo mira la imagen de la pantalla.

Tocar imagen PRO

Busca una imagen en la pantalla y tócala, esté donde esté; perfecto para botones que cambian de sitio.

  1. Toca «Añadir acción» y elige Tocar imagen
  2. Toca «Elegir imagen» y elige «Recortar de la pantalla»
  3. Abre la pantalla con la imagen y toca Capturar
  4. Ajusta el marco a la imagen y toca OK
  5. Vuelve, toca Probar y abre la app

▶ AutoGest espera la caja de regalo y la toca

Consejos
  • Funciona en juegos, porque AutoGest mira la imagen de la pantalla, no la estructura de la app.
  • Recorta solo el botón, sin el fondo que lo rodea.

Tocar texto (OCR) PRO

Lee el texto de una captura con reconocimiento de texto (OCR) en el propio móvil y tócalo; funciona incluso en juegos que dibujan su propio texto.

  1. Toca «Añadir acción» y elige Tocar texto (OCR)
  2. Escribe el texto del botón
  3. Toca Probar y abre la app

▶ AutoGest lee la imagen de la pantalla —también en juegos— y toca el texto

Consejos
  • Elige el alfabeto correcto para chino, japonés o coreano; Latin sirve para español, inglés, vietnamita y más.
  • Reduce el área de búsqueda para leer más rápido y con más precisión.
  • El reconocimiento se hace en tu móvil; no se envía nada a ningún sitio.

Esperar texto (OCR) PRO

Espera hasta que un texto aparezca (o desaparezca) en la imagen de la pantalla, sin tocar.

  1. Toca «Añadir acción» y elige Esperar texto (OCR)
  2. Escribe el texto que hay que esperar
  3. Añade un paso Tocar en «Correr»
  4. Vuelve, toca Probar y abre la app

▶ AutoGest espera «YA» y luego toca «Correr»

Consejos
  • Útil en pantallas de juego como «¿Listos?… ¡Ya!», «Victoria» o el final de una cuenta atrás.
  • Elige un área para esperar más rápido y no confundir la misma palabra en otro sitio.

Leer texto (OCR) PRO

Lee el texto de una zona de la imagen de la pantalla y guárdalo en una variable para los pasos siguientes.

  1. Toca «Añadir acción» y elige Leer texto (OCR)
  2. Toca «Elegir zona», abre la pantalla y toca Capturar
  3. Enmarca el código y toca OK
  4. Vuelve, elige «Solo el número» y una variable donde guardarlo
  5. Añade Pegar texto en el campo e inserta la variable
  6. Añade un paso Tocar en «Confirmar»
  7. Toca Probar y abre la app

▶ AutoGest lee el código de la imagen y lo escribe

Consejos
  • Elige «Solo el número» para quedarte solo con los dígitos: puntuaciones, precios o códigos.
  • Usa la variable en Pegar texto o compárala en un bloque Si… entonces.

Tocar texto

Escribe el texto que muestra un botón; al ejecutar, AutoGest encuentra ese texto en la pantalla y lo toca.

  1. Toca «Añadir acción» y elige Tocar texto
  2. Escribe el texto que muestra el botón
  3. Toca Probar y abre la app

▶ Esté donde esté el botón, AutoGest encuentra el texto y lo toca

Consejos
  • Lee la estructura de la app, así que no funciona en juegos que dibujan su propio texto; ahí usa Tocar texto (OCR).
  • No importan mayúsculas ni minúsculas, y basta con que el texto contenga lo que escribiste.

Tocar nodo PRO

Captura la pantalla, toca un elemento y AutoGest recuerda cómo volver a encontrarlo, incluso botones que solo tienen un icono.

  1. Toca «Añadir acción» y elige Tocar nodo
  2. Toca «Elegir nodo», abre la app y toca Capturar
  3. Toca el botón que quieres y luego «Elegir nodo»
  4. Vuelve y elige cómo encontrar el nodo
  5. Toca Probar y abre la app

▶ AutoGest encuentra el botón del corazón y lo toca

Consejos
  • Búscalo por text o content-desc cuando no cambian; evita resource-id si la app lo cambia entre versiones.
  • Quita las partes que cambian cada vez (como contadores) para que se siga encontrando.

Leer texto en pantalla PRO

Elige un elemento de la pantalla y copia su texto en una variable, sin tocarlo.

  1. Toca «Añadir acción» y elige Leer texto en pantalla
  2. Toca «Elegir nodo», abre la app y toca Capturar
  3. Toca el código y luego «Elegir nodo»
  4. Vuelve y elige una variable donde guardarlo
  5. Añade Pegar texto en el campo e inserta la variable
  6. Añade un paso Tocar en «Confirmar»
  7. Toca Probar y abre la app

▶ AutoGest copia el código y lo escribe

Consejos
  • Ideal para códigos de un solo uso, números de pedido o saldos que muestra una app.
  • Lee la estructura de la app; para juegos usa Leer texto (OCR).

Esperar y detectar notificación PRO

Espera una notificación que contenga el texto que elegiste, léela en voz alta y continúa el script.

  1. Toca «Añadir acción» y elige Esperar y detectar notificación
  2. Toca «Elegir notificación de muestra» y elige una notificación
  3. Escribe las palabras que debe contener la notificación
  4. Toca «Usar esta muestra»
  5. Añade un paso Tocar en «Confirmar pedido»
  6. Vuelve, toca Probar y abre la app
  7. Cuando un cliente hace un pedido…

▶ AutoGest lee la notificación en voz alta y confirma

Consejos
  • Elige una notificación real como muestra y toca las palabras que hay que esperar; las partes que cambian (como el número de pedido) se comparan con flexibilidad.
  • Un script que solo espera notificaciones puede ejecutarse en segundo plano, incluso con la pantalla apagada.
  • El contenido de las notificaciones se queda en tu móvil y nunca se escribe en el registro.

Si… entonces PRO

Ejecuta algunos pasos solo cuando se cumple una condición: una imagen, un color, un texto, el número de ronda o una variable.

  1. Toca «Añadir acción» y elige Si… entonces
  2. Elige «Texto» y escribe el texto que hay que ver
  3. Desactiva la rama «Si no» y toca «Listo»
  4. Añade a la rama «Entonces»: paso Tocar en el botón de cerrar (✕)
  5. Vuelve, toca Probar y abre la app

▶ AutoGest ve «Publicidad» y toca cerrar

Consejos
  • Activa la rama «Si no» para ejecutar otros pasos cuando la condición es falsa.
  • Los bloques tienen un solo nivel; para anidar, separa la lógica en otro script y usa Llamar script.

Repetir hasta PRO

Repite los pasos del bloque hasta que se cumpla una condición, o durante un número de rondas.

  1. Toca «Añadir acción» y elige Repetir hasta
  2. Parar con «Texto»: escribe el texto que aparece al terminar
  3. Añade al bucle: paso Tocar en «Cargar más»
  4. Vuelve, toca Probar y abre la app

▶ AutoGest toca «Cargar más» hasta que aparece «No hay más noticias»

Consejos
  • Pon siempre un máximo de rondas para que el script no se ejecute para siempre por error.

Detener script PRO

Termina toda la ejecución cuando se cumple una condición; por ejemplo, cuando te quedas sin turnos o energía.

  1. Añade un paso Tocar en «Girar»
  2. Vuelve y añade Detener script
  3. Parar cuando aparezca el texto «Sin tiradas»
  4. Repite el script sin límite
  5. Toca Probar y abre la app

▶ Tras la última tirada, AutoGest se detiene solo

Consejos
  • Con un bucle sin límite, es la forma limpia de terminar.
  • Dentro de una rama de Si… entonces puede detenerse al momento, sin condición.

Siguiente vuelta PRO

Salta el resto de esta ronda y empieza la siguiente cuando se cumple una condición.

  1. Añade un paso Tocar en «Siguiente»
  2. Añade Siguiente vuelta cuando aparezca «Patrocinado»
  3. Añade un paso Tocar en «Me gusta»
  4. Repite el script 4 veces
  5. Toca Probar y abre la app

▶ AutoGest da me gusta a las publicaciones 1 y 3 y salta las patrocinadas

Consejos
  • Útil para saltar anuncios o elementos que no quieres al recorrer una lista.
  • Salta al final del bucle más cercano del mismo script.

  2. Toca «Elegir script» y elige el script que se llamará
  3. Elige cuántas veces llamarlo
  4. Toca Probar y abre la app

▶ AutoGest ejecuta «Pulsar el botón» 3 veces

Consejos
  • Elige cuántas veces seguidas llamarlo.
  • El script llamado usa el ritmo de este script.

Guardar en variable PRO

Da un valor a una variable o súmale un número: contadores, totales acumulados, texto que recordar.

  1. Toca «Añadir acción» y elige Guardar en variable
  2. Pon nombre a la nueva variable y toca «Añadir variable»
  3. Haz que el paso sume 1 a la variable
  4. Añade Pegar texto en el chat: «Mensaje #» + la variable
  5. Añade un paso Tocar en «Enviar»
  6. Repite el script 3 veces
  7. Toca Probar y abre la app

▶ En cada ronda el número sube: 1, 2, 3

Consejos
  • Inserta {nombre} en cualquier campo de texto para usar el valor de la variable.
  • Las variables solo duran una ejecución: pulsa Detener y se reinician.
