Anleitung

Tippen

Die einfachste Aktion: AutoGest tippt genau auf den Punkt, den du auf dem Bildschirm gewählt hast.

  1. Tippe auf „Aktion hinzufügen“, wähle Tippen
  2. Tippe auf „Punkt hinzufügen“
  3. Öffne die App, zieh das Fadenkreuz auf die Stelle
  4. Tippe auf OK, um den Punkt zu speichern
  5. Zurück in AutoGest ist der Punkt eingetragen
  6. Tippe auf Testlauf und öffne die App

▶ AutoGest tippt genau auf die gewählte Stelle

Tipps
  • Punkte werden an die Bildschirmgröße angepasst, so trifft das Skript auch auf einem Handy mit anderem Bildschirm.
  • Unter Allgemeine Einstellungen stellst du die Pause zwischen Schritten und auf Wunsch eine kleine Tippabweichung ein.
  • Der Knopf wandert? Nutze Auf Bild tippen, Auf Text tippen (OCR) oder Auf Text tippen, damit AutoGest ihn zuerst sucht.

Schnell tippen

Tippe immer wieder auf einen Punkt, 1- bis 20-mal pro Sekunde – für Schaltflächen, die man oft drücken muss.

  1. Tippe auf „Aktion hinzufügen“, wähle Schnell tippen
  2. Tippe auf „Punkt hinzufügen“
  3. Öffne die App, setz das Fadenkreuz auf den Knopf
  4. Tippe auf OK, um den Punkt zu speichern
  5. Zurück in AutoGest: Anzahl der Tipps senken
  6. Tippe auf Testlauf und öffne die App

▶ AutoGest tippt 30-mal, 10-mal pro Sekunde

Tipps
  • Stopp nach einer Anzahl, nach einer Zeit oder erst, wenn du auf Stopp tippst.
  • Ab 10 Tipps pro Sekunde kommen manche Apps nicht mit und verpassen Tipps; senke dann die Geschwindigkeit.

Lange drücken

Einen Punkt so lange gedrückt halten, wie du willst – für Halten-zum-Bestätigen, Kontextmenüs, Markieren durch Ziehen.

  1. Tippe auf „Aktion hinzufügen“, wähle Lange drücken
  2. Tippe auf „Punkt hinzufügen“
  3. Öffne die App, setz das Fadenkreuz auf den Knopf
  4. Tippe auf OK, um den Punkt zu speichern
  5. Zurück in AutoGest: wähle die Haltedauer
  6. Tippe auf Testlauf und öffne die App

▶ AutoGest hält den Knopf 2 s, er entsperrt

Tipps
  • Für „zum Bestätigen halten“ etwas länger wählen, als die App verlangt.

Wischen

Mit dem Finger vom Start- zum Endpunkt ziehen – zum Entsperren wischen, Regler schieben, Seiten blättern.

  1. Tippe auf „Aktion hinzufügen“, wähle Wischen
  2. Wähle den Startpunkt
  3. Zurück, wähle den Endpunkt
  4. Zurück, wähle die Wischdauer
  5. Tippe auf Testlauf und öffne die App

▶ AutoGest wischt vom Start- zum Endpunkt

Tipps
  • Kurze Dauer ist ein schnelles Wischen, lange Dauer ein langsames Ziehen (Drag & Drop, Regler).

Scrollen

  2. Wähle Richtung und Dauer

Tipps
  • Kombiniere es mit Wiederholen bis, um zu scrollen, bis das Gesuchte erscheint.

Zwei-Finger-Geste

Zwei Finger um einen Punkt spreizen, zusammenziehen oder drehen – zum Vergrößern, Verkleinern oder Drehen einer Karte oder eines Fotos.

  1. Tippe auf „Aktion hinzufügen“, wähle Zwei-Finger-Geste
  2. Tippe auf „Punkt hinzufügen“, ziele auf die Kartenmitte, tippe auf OK
  3. Zurück in AutoGest: Standard ist „Größer“, „Mittel“
  4. Füge einen zweiten Schritt auf demselben Punkt hinzu
  5. Zurück, wähle „Kleiner“
  6. Füge einen dritten Schritt hinzu, wieder in der Kartenmitte
  7. Zurück, wähle „Drehen“ – dreht im Uhrzeigersinn
  8. Tippe auf Testlauf und öffne die App

▶ AutoGest zoomt hinein, heraus und dreht dann die Karte

Tipps
  • Gering / Mittel / Stark zoomt etwa ×1,5 / ×2 / ×3 oder dreht um 30° / 90° / 180°.
  • Eine sehr schnelle Geste lässt manche Apps nach dem Loslassen weitergleiten; 1000ms ergibt ein gleichmäßiges Ergebnis.
  • Die Aufnahme erfasst Zwei-Finger-Gesten noch nicht: füge diesen Schritt von Hand hinzu.

Text einfügen

Tippe in ein Textfeld und füge den vorbereiteten Text komplett ein – schnell und mit allen Umlauten.

  1. Tippe auf „Aktion hinzufügen“, wähle Text einfügen
  2. Tippe auf „Punkt hinzufügen“, ziel auf das Textfeld
  3. Zurück, gib den Text zum Einfügen ein
  4. Tippe auf Testlauf und öffne die App

▶ AutoGest fügt den ganzen Text ins Feld ein

Tipps
  • Setze mit Variable einfügen eine Variable ein, um einen vorher gelesenen Wert einzufügen.
  • Die App blockiert Einfügen? Nutze Zeichen tippen, um jede Taste der Tastatur zu tippen.

Zeichen tippen PRO

Nimm jede Taste auf, die du tippst; beim Ausführen tippt AutoGest dieselben Tasten erneut.

  1. Tippe auf „Aktion hinzufügen“, wähle Zeichen tippen
  2. Tippe ins Aufnahmefeld, schreib auf der Tastatur
  3. Tippe auf „Fertig“, um die Tasten zu speichern
  4. Wähle das Feld zum Schreiben (optional)
  5. Zurück, auf Testlauf tippen, App öffnen

▶ AutoGest tippt ins Feld und spielt jede Taste ab

Tipps
  • Nutze beim Aufnehmen und Ausführen dieselbe Tastatur (und dieselbe Feldart), denn AutoGest tippt nach Tastenposition.
  • Danach prüft AutoGest das Feld; passt der Text nicht, meldet der Schritt einen Fehler und hört auf.
  • Nicht jede Taste nötig? Stell die Karte auf Text einfügen um.

Warten

Pause vor dem nächsten Schritt – damit ein Bildschirm lädt, eine Animation endet oder ein Timer abläuft.

  1. Tippe auf „Aktion hinzufügen“, wähle Warten
  2. Gib die Wartezeit ein (ms)
  3. Füge einen Tippen-Schritt hinzu, um die Pause zu sehen
  4. Wiederhole das Skript 2-mal in „Allgemeine Einstellungen“
  5. Tippe auf Testlauf und öffne die App

▶ Zwischen den Tipps liegen 3 s plus Schrittpause

Tipps
  • Jeder Schritt wartet schon eine kurze Pause (unter Allgemeine Einstellungen); füge Warten nur hinzu, wenn es länger sein muss.
  • Du wartest, bis etwas erscheint? Auf Bild warten, Auf Text warten (OCR) oder Auf Farbe warten machen sofort weiter.

Auf Bild warten PRO

Warten, bis ein Bild auf dem Bildschirm erscheint (oder verschwindet), ohne zu tippen – dann laufen die nächsten Schritte.

  1. Tippe auf „Aktion hinzufügen“, wähle Auf Bild warten
  2. Tippe auf „Bild auswählen“, wähle „Vom Bildschirm zuschneiden“
  3. Öffne den Bildschirm, tippe auf Aufnehmen, rahme das Bild
  4. Zurück, füge einen Tippen-Schritt dort hinzu, wo das Bild erscheint
  5. Zurück, auf Testlauf tippen, App öffnen

▶ AutoGest wartet auf den Briefkasten, dann folgt der Tippen-Schritt

Tipps
  • Schneide das Bild eng zu, ohne wechselnden Hintergrund.
  • Senke die Mindestübereinstimmung, wenn das Bild jedes Mal etwas anders aussieht.

Auf Farbe warten PRO

Einen Punkt beobachten, bis er eine gewählte Farbe hat (oder die Farbe wechselt) – eine Ampel wird grün, ein Knopf aktiv.

  1. Tippe auf „Aktion hinzufügen“, wähle Auf Farbe warten
  2. Tippe auf „Punkt hinzufügen“, ziel auf die Stelle mit der Farbe
  3. Zurück: AutoGest hat die Farbe dort schon gelesen
  4. Füge einen Tippen-Schritt auf „Los“ hinzu
  5. Zurück, auf Testlauf tippen, App öffnen

▶ AutoGest wartet auf Grün und tippt dann auf „Los“

Tipps
  • Wähle den Punkt, während die gewünschte Farbe zu sehen ist: AutoGest liest sie für dich.
  • Es zählt nur das Bildschirmbild, daher klappt es auch, wo die App keinen Text und keine Elemente bereitstellt.

Auf Bild tippen PRO

Ein Bild auf dem Bildschirm finden und antippen, egal wo es ist – perfekt für wandernde Knöpfe.

  1. Tippe auf „Aktion hinzufügen“, wähle Auf Bild tippen
  2. Tippe auf „Bild auswählen“, wähle „Vom Bildschirm zuschneiden“
  3. Öffne den Bildschirm mit dem Bild, tippe auf Aufnehmen
  4. Zieh den Rahmen eng ums Bild, tippe auf OK
  5. Zurück, auf Testlauf tippen, App öffnen

▶ AutoGest wartet auf den Briefkasten und tippt ihn an

Tipps
  • AutoGest sieht das Bildschirmbild an, nicht den App-Aufbau, und findet so auch Schaltflächen ohne Text.
  • Schneide nur den Knopf aus, ohne den Hintergrund.

Auf Text tippen (OCR) PRO

Text in einem Screenshot per Texterkennung (OCR) direkt auf dem Handy lesen und antippen – findet auch Text, den eine App als Bild zeichnet.

  1. Tippe auf „Aktion hinzufügen“, wähle Auf Text tippen (OCR)
  2. Gib den Text auf dem Knopf ein
  3. Tippe auf Testlauf und öffne die App

▶ AutoGest liest das Bildschirmbild und tippt den Text an

Tipps
  • Wähle für Chinesisch, Japanisch oder Koreanisch die passende Schrift; Latin deckt Deutsch, Englisch, Spanisch und mehr ab.
  • Verkleinere den Suchbereich für schnelleres, genaueres Lesen.
  • Die Erkennung läuft auf deinem Handy; nichts wird gesendet.

Auf Text warten (OCR) PRO

  1. Tippe auf „Aktion hinzufügen“, wähle Auf Text warten (OCR)

Text lesen (OCR) PRO

Den Text in einem Bereich des Bildschirmbilds lesen und für spätere Schritte in einer Variable speichern.

  1. Tippe auf „Aktion hinzufügen“, wähle Text lesen (OCR)

  3. Rahme die Nummer, tippe auf OK

▶ AutoGest liest die Bestellnummer vom Bild und gibt sie ein

  • Wähle „Nur die Zahl“, um nur die Ziffern zu behalten – Preise, Summen oder Bestellnummern.

Auf Text tippen

Gib den Text auf einem Knopf ein; beim Ausführen findet AutoGest diesen Text auf dem Bildschirm und tippt darauf.

  1. Tippe auf „Aktion hinzufügen“, wähle Auf Text tippen
  2. Gib den Text auf dem Knopf ein
  3. Tippe auf Testlauf und öffne die App

▶ Egal wo der Knopf ist: AutoGest findet den Text und tippt

Tipps
  • Es liest den App-Aufbau und sieht daher keinen Text, der als Bild gezeichnet ist – dort Auf Text tippen (OCR) nutzen.
  • Groß- und Kleinschreibung zählen nicht; der Text muss nur das Eingegebene enthalten.

Auf Knoten tippen PRO

Bildschirm erfassen, ein Element antippen – AutoGest merkt sich, wie es wiedergefunden wird, auch reine Symbolknöpfe.

  1. Tippe auf „Aktion hinzufügen“, wähle Auf Knoten tippen
  2. Tippe auf „Knoten wählen“, öffne die App, tippe auf Aufnehmen
  3. Tippe auf den gewünschten Knopf, dann „Knoten wählen“
  4. Zurück, wähle, wie der Knoten gefunden wird
  5. Tippe auf Testlauf und öffne die App

▶ AutoGest findet den Lichtschalter und tippt ihn an

Tipps
  • Suche über text oder content-desc, wenn sie gleich bleiben; meide resource-id, wenn die App sie zwischen Versionen ändert.
  • Entferne wechselnde Teile (etwa Zähler), damit der Knoten wiedergefunden wird.

Wenn… dann PRO

Einige Schritte nur ausführen, wenn eine Bedingung erfüllt ist – ein Bild, eine Farbe, ein Text, die Rundennummer oder eine Variable.

  1. Tippe auf „Aktion hinzufügen“, wähle Wenn… dann
  2. Wähle „Text“, gib den gesuchten Text ein
  3. Schalte den Sonst-Zweig aus, tippe auf „Fertig“
  4. Im Dann-Zweig: Tippen-Schritt auf den Schließen-Knopf (✕)
  5. Zurück, auf Testlauf tippen, App öffnen

▶ AutoGest sieht „Neuigkeiten“ und tippt auf Schließen

Tipps
  • Schalte den Sonst-Zweig ein, um andere Schritte auszuführen, wenn die Bedingung falsch ist.
  • Blöcke haben nur eine Ebene; zum Verschachteln in ein anderes Skript auslagern und Skript aufrufen nutzen.

Tipps

Skript stoppen PRO

Den ganzen Lauf beenden, wenn eine Bedingung eintritt – etwa wenn eine Liste zu Ende ist oder eine Aufgabe „fertig“ meldet.

  1. Füge einen Tippen-Schritt auf „Erledigt“ hinzu
  2. Zurück, füge Skript stoppen hinzu
  3. Stoppen, wenn der Text „Alle Aufgaben erledigt“ erscheint
  4. Wiederhole das Skript ohne Limit
  5. Tippe auf Testlauf und öffne die App

▶ Nach der letzten Aufgabe hört AutoGest von selbst auf

Tipps
  • Wenn das Skript ohne Begrenzung wiederholt, ist das der saubere Weg zum Ende.
  • Im Zweig eines Wenn…-dann-Blocks kann es sofort und ohne Bedingung stoppen.

  • Praktisch, um beim Durchgehen einer Liste Unnötiges zu überspringen.

  2. Tippe auf „Skript auswählen“, wähle das aufzurufende Skript

  4. Tippe auf Testlauf und öffne die App
