탭

가장 기본적인 동작: 화면에서 고른 위치를 AutoGest가 정확히 탭합니다.

  1. “동작 추가”을 누르고 탭 선택
  2. “지점 추가” 누르기
  3. 앱을 열고 조준점을 위치로 끌기
  4. OK를 눌러 좌표 저장
  5. AutoGest로 돌아오면 좌표가 입력됨
  6. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 고른 위치를 정확히 탭

팁
  • 좌표는 화면 크기에 맞춰 환산되므로 화면이 다른 휴대폰에서도 같은 곳을 탭합니다.
  • 공통 설정에서 단계 사이 쉬는 시간과, 원하면 탭 위치의 작은 흔들림을 정할 수 있습니다.
  • 버튼 위치가 바뀌나요? 이미지 탭, 텍스트 탭(OCR), 텍스트 탭로 먼저 찾게 하세요.

↑ 동작 목록으로

연속 탭

한 곳을 초당 1~20번 계속 탭합니다. 여러 번 눌러야 하는 버튼에 쓰세요.

  1. “동작 추가”을 누르고 연속 탭 선택
  2. “지점 추가” 누르기
  3. 앱을 열고 조준점을 버튼에 맞추기
  4. OK를 눌러 좌표 저장
  5. AutoGest로 돌아와 탭 횟수 줄이기
  6. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 30번, 초당 10번 탭

팁
  • 횟수나 시간으로 멈추거나, 정지를 누를 때까지 계속할 수 있습니다.
  • 초당 10번이 넘으면 일부 앱이 따라가지 못해 탭이 빠질 수 있습니다. 그럴 땐 속도를 낮추세요.
  • 무작위 흔들림 옵션을 켜면 탭 간격이 조금씩 달라집니다.

↑ 동작 목록으로

길게 누르기

고른 시간만큼 한 곳을 길게 누릅니다. 길게 눌러 확인하는 버튼, 컨텍스트 메뉴, 끌어서 선택에.

  1. “동작 추가”을 누르고 길게 누르기 선택
  2. “지점 추가” 누르기
  3. 앱을 열고 조준점을 버튼에 맞추기
  4. OK를 눌러 좌표 저장
  5. AutoGest로 돌아와 누를 시간 고르기
  6. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 버튼을 2초 누르고 잠금 해제

팁
  • “길게 눌러 확인” 버튼은 앱이 요구하는 시간보다 조금 길게 정하세요.

↑ 동작 목록으로

스와이프

시작 위치에서 끝 위치까지 손가락을 끕니다. 밀어서 잠금 해제, 슬라이더 이동, 페이지 넘기기에.

  1. “동작 추가”을 누르고 스와이프 선택
  2. 시작 위치 고르기
  3. 돌아와 끝 위치 고르기
  4. 돌아와 스와이프 시간 고르기
  5. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 시작 위치에서 끝 위치로 스와이프

팁
  • 짧으면 빠른 넘김, 길면 천천히 끌기(끌어다 놓기, 슬라이더)입니다.

↑ 동작 목록으로

스크롤

화면 가운데를 한 번 스와이프해 목록을 위·아래·왼쪽·오른쪽으로 스크롤합니다. 좌표를 고를 필요가 없습니다.

  1. “동작 추가”을 누르고 스크롤 선택
  2. 방향과 시간 고르기
  3. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 화면 가운데를 스와이프해 스크롤

팁
  • 조건까지 반복와 함께 쓰면 찾는 것이 나올 때까지 스크롤할 수 있습니다.

↑ 동작 목록으로

텍스트 붙여넣기

입력란을 누르고 준비한 내용을 한 번에 채웁니다. 빠르고 글자가 깨지지 않습니다.

  1. “동작 추가”을 누르고 텍스트 붙여넣기 선택
  2. “지점 추가” 누르기, 입력란에 조준
  3. 돌아와 붙여 넣을 내용 입력
  4. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 내용 전체를 입력란에 붙여 넣기

팁
  • ||로 여러 내용을 나누면 실행할 때마다 AutoGest가 하나를 무작위로 고릅니다.
  • 변수 넣기로 변수를 넣으면 실행 중에 읽은 값을 붙여 넣을 수 있습니다.
  • 붙여 넣기를 막는 앱이라면 문자 입력로 키를 하나씩 누르세요.

↑ 동작 목록으로

문자 입력 PRO

키보드에서 누른 키를 하나씩 기록하고, 실행할 때 AutoGest가 같은 키를 내 리듬대로 누릅니다.

  1. “동작 추가”을 누르고 문자 입력 선택
  2. 키 기록 칸을 누르고 키보드로 입력
  3. “완료”을 눌러 키 저장
  4. 입력할 칸 고르기(선택)
  5. 돌아와 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 칸을 누르고 키를 하나씩 다시 입력

팁
  • AutoGest는 키 위치대로 누르므로 기록과 실행에 같은 키보드(같은 종류의 입력란)를 쓰세요.
  • 입력 후 AutoGest가 칸을 확인하고, 글자가 다르면 오류를 내고 입력을 멈춥니다.
  • 키를 하나씩 누를 필요가 없다면 카드를 텍스트 붙여넣기로 바꾸세요.

↑ 동작 목록으로

대기

다음 단계 전에 잠시 멈춥니다. 화면 로딩, 애니메이션 끝, 타이머 종료를 기다릴 때.

  1. “동작 추가”을 누르고 대기 선택
  2. 대기 시간(ms) 입력
  3. 탭 단계를 추가해 간격 보기
  4. “공통 설정”에서 스크립트 2회 반복
  5. 테스트 실행을 누르고 앱을 열기

▶ 탭 간격은 3초 + 단계 사이 쉼

팁
  • 각 단계는 이미 짧은 무작위 쉼을 둡니다(공통 설정에서 설정). 더 길게 기다릴 때만 추가하세요.
  • 무언가가 나타나길 기다린다면 이미지 대기, 텍스트 대기(OCR), 색상 대기가 나타나는 즉시 진행합니다.

↑ 동작 목록으로

이미지 대기 PRO

화면에 이미지가 나타날(또는 사라질) 때까지 누르지 않고 기다린 뒤 다음 단계를 실행합니다.

  1. “동작 추가”을 누르고 이미지 대기 선택
  2. “이미지 선택”을 누르고 “화면에서 자르기” 선택
  3. 화면을 열고 캡처을 눌러 이미지 감싸기
  4. 돌아와 이미지가 나타나는 곳에 탭 추가
  5. 돌아와 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 선물 상자를 기다린 뒤 탭 실행

팁
  • 찾을 대상에 딱 맞게 자르고, 바뀌는 배경은 빼세요.
  • 매번 조금씩 달라 보이면 최소 일치도를 낮추세요.

↑ 동작 목록으로

색상 대기 PRO

한 지점이 고른 색이 될(또는 색이 바뀔) 때까지 지켜봅니다. 신호가 초록으로 바뀌거나 버튼이 활성화될 때.

  1. “동작 추가”을 누르고 색상 대기 선택
  2. “지점 추가” 누르기, 색을 기다릴 위치에 조준
  3. 돌아오기: AutoGest가 그 위치의 색을 읽어 둠
  4. “출발”에 탭 단계 추가
  5. 돌아와 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 초록불을 기다렸다가 “출발” 탭

팁
  • 원하는 색이 보일 때 위치를 고르면 AutoGest가 색을 읽어 줍니다.
  • 화면 이미지만 보므로 게임에서도 쓸 수 있습니다.

↑ 동작 목록으로

이미지 탭 PRO

화면에서 이미지를 찾아 어디에 있든 탭합니다. 위치가 바뀌는 버튼에 딱입니다.

  1. “동작 추가”을 누르고 이미지 탭 선택
  2. “이미지 선택”을 누르고 “화면에서 자르기” 선택
  3. 이미지가 있는 화면을 열고 캡처
  4. 틀을 이미지에 딱 맞추고 OK
  5. 돌아와 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 선물 상자가 나오길 기다렸다가 탭

팁
  • AutoGest는 앱 구조가 아니라 화면 이미지를 보므로 게임에서도 됩니다.
  • 주변 배경 없이 버튼만 자르세요.

↑ 동작 목록으로

텍스트 탭(OCR) PRO

휴대폰에서 바로 돌아가는 글자 인식(OCR)으로 스크린샷의 글자를 읽고 탭합니다. 글자를 직접 그리는 게임에서도 됩니다.

  1. “동작 추가”을 누르고 텍스트 탭(OCR) 선택
  2. 버튼의 글자 입력
  3. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 화면 이미지를 읽고(게임에서도) 글자를 탭

팁
  • 한국어 글자는 “한국어” 문자를 고르세요. 영어 등은 Latin으로 읽습니다.
  • 찾을 영역을 좁히면 더 빠르고 정확합니다.
  • 인식은 휴대폰 안에서만 이루어지며 어디로도 보내지 않습니다.

↑ 동작 목록으로

텍스트 대기(OCR) PRO

화면 이미지에 글자가 나타날(또는 사라질) 때까지 누르지 않고 기다립니다.

  1. “동작 추가”을 누르고 텍스트 대기(OCR) 선택
  2. 기다릴 글자 입력
  3. “달리기”에 탭 단계 추가
  4. 돌아와 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 “출발”를 기다렸다가 “달리기” 탭

팁
  • “준비… 출발!”, “승리”, 카운트다운 끝 같은 게임 화면에 좋습니다.
  • 영역을 고르면 더 빨리 기다리고 다른 곳의 같은 글자와 헷갈리지 않습니다.

↑ 동작 목록으로

글자 읽기(OCR) PRO

화면 이미지의 한 영역에서 글자를 읽어 변수에 저장해 다음 단계에서 씁니다.

  1. “동작 추가”을 누르고 글자 읽기(OCR) 선택
  2. “영역 선택”을 누르고 화면을 열어 캡처
  3. 코드를 감싸고 OK
  4. 돌아와 “숫자만”와 저장할 변수 고르기
  5. 입력란에 텍스트 붙여넣기 추가, 변수 삽입
  6. “확인”에 탭 단계 추가
  7. 테스트 실행을 누르고 앱을 열기

▶ AutoGest가 이미지에서 코드를 읽어 입력

팁
  • “숫자만”를 고르면 숫자만 남깁니다. 점수, 가격, 코드에.

버튼에 표시된 글자를 입력하면, 실행할 때 AutoGest가 화면에서 그 글자를 찾아 탭합니다.

  1. “동작 추가”을 누르고 텍스트 탭 선택
  2. 버튼에 표시된 글자 입력
  3. 테스트 실행을 누르고 앱을 열기

▶ 버튼이 어디 있든 AutoGest가 글자를 찾아 탭

팁
  • 앱 구조를 읽으므로 글자를 직접 그리는 게임에서는 안 됩니다. 그럴 땐 텍스트 탭(OCR)를 쓰세요.
  • 대소문자는 구분하지 않고, 입력한 글자를 포함하기만 하면 됩니다.
