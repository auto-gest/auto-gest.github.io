Click

The most basic action: AutoGest taps exactly the point you picked on the screen.

  1. Tap “Add action”, choose Click
  2. Tap “Add point”
  3. Open the app, drag the crosshair to the spot
  4. Tap OK to save the point
  5. Back in AutoGest, the point is filled in
  6. Tap Test run, then open the app

▶ AutoGest taps exactly the chosen spot

Tips
  • Points are scaled to the screen size, so the script still hits the right spot on a phone with a different screen.
  • In General settings you set the pause between steps and a small tap offset, so it feels like a real person.
  • The button moves around? Use Click image, Click text (OCR) or Click text so AutoGest finds it first.

Rapid click

Tap one point over and over, from 1 to 20 times per second — great for games that need fast tapping.

  1. Tap “Add action”, choose Rapid click
  2. Tap “Add point”
  3. Open the app, put the crosshair on the button
  4. Tap OK to save the point
  5. Back in AutoGest, lower the tap count
  6. Tap Test run, then open the app

▶ AutoGest taps 30 times, 10 taps per second

Tips
  • Stop after a number of taps, after a time, or keep going until you press Stop.
  • Above 10 taps per second is faster than a human hand; some apps may treat it as unusual.
  • Turn on the natural rhythm so the gaps between taps vary slightly, like a real finger.

Swipe

Drag a finger from a start point to an end point — swipe to unlock, move a slider, flick through pages.

  1. Tap “Add action”, choose Swipe
  2. Pick the start point
  3. Go back, pick the end point
  4. Go back, choose the swipe duration
  5. Tap Test run, then open the app

Paste text

Tap a text field and fill in the whole text you prepared — fast, and every accent and character comes out right.

  1. Tap “Add action”, choose Paste text
  2. Tap “Add point”, aim at the text field
  3. Go back, enter the text to paste
  4. Tap Test run, then open the app

▶ AutoGest pastes the whole text into the field

Tips
  • Separate several texts with || and AutoGest picks one at random each run.
  • Insert a variable with Insert variable to paste a value read earlier in the run.
  • The app blocks pasting? Use Type characters to tap each key like a person typing.

Type characters PRO

Record each key you tap on the keyboard; when the script runs, AutoGest taps the same keys with your typing rhythm.

  1. Tap “Add action”, choose Type characters
  2. Tap the key recording box, type on the keyboard
  3. Tap “Done” to save the key taps
  4. Pick the field to type into (optional)
  5. Go back, tap Test run, then open the app

▶ AutoGest taps the field, then replays each key

Tips
  • Use the same keyboard (and the same kind of field) when recording and running, because AutoGest taps by key position.
  • After typing, AutoGest checks the field; if the text does not match, the step reports an error and stops typing.
  • No need to tap each key? Switch the card to Paste text.

Wait

Pause before the next step — let a screen load, an animation finish, or a timer run out.

  1. Tap “Add action”, choose Wait
  2. Enter the wait time (ms)
  3. Add a Click step to see the pause
  4. Repeat the script 2 times in “General settings”
  5. Tap Test run, then open the app

▶ The taps come 3 s apart, plus the step pause

Tips
  • Every step already waits a short random pause (set in General settings); add a Wait only when you need longer.
  • Waiting for something to appear? Wait for image, Wait for text (OCR) or Wait for color continue as soon as it is there.

Wait for image PRO

Wait until a picture appears (or disappears) on the screen, without tapping — then the next steps run.

  1. Tap “Add action”, choose Wait for image
  2. Tap “Pick image”, choose “Crop from the screen”
  3. Open the screen, tap Capture, frame the image
  4. Go back, add a Click where the image shows up
  5. Go back, tap Test run, then open the app

▶ AutoGest waits for the gift box, then runs the Click

Tips
  • Crop the image tight around the thing you want, leaving out backgrounds that change.
  • Lower the minimum match if the image looks slightly different each time.

Click text (OCR) PRO

Read the text in a screenshot with on-device text recognition (OCR) and tap it — works even in games that draw their own text.

  1. Tap “Add action”, choose Click text (OCR)
  2. Enter the text on the button
  3. Tap Test run, then open the app

▶ AutoGest reads the screen image — even in games — and taps the text

Tips
  • Choose the right script for Chinese, Japanese or Korean text; Latin covers English, Vietnamese, Spanish and more.
  • Narrow the search area to make reading faster and more accurate.
  • Recognition runs on your phone; nothing is sent anywhere.

  2. Tap “Pick area”, open the screen, tap Capture

  • Use the variable in Paste text, or compare it in an If… then block.

Click text

Type the text shown on a button; when the script runs, AutoGest finds that text on the screen and taps it.

  1. Tap “Add action”, choose Click text
  2. Enter the text shown on the button
  3. Tap Test run, then open the app

▶ Wherever the button is, AutoGest finds the text and taps

Tips
  • It reads the app’s layout, so it does not work in games that draw their own text — use Click text (OCR) there.
  • Upper and lower case do not matter, and the text only needs to contain what you typed.

Click node PRO

Capture the screen, tap an element, and AutoGest remembers how to find it again — even buttons with only an icon.

  1. Tap “Add action”, choose Click node
  2. Tap “Pick node”, open the app, tap Capture
  3. Tap the button you want, then “Pick node”
  4. Go back, choose how to find the node
  5. Tap Test run, then open the app

▶ AutoGest finds the heart button and taps it

Tips
  • Find it by text or content-desc when they stay the same; avoid resource-id if the app changes it between versions.
  • Remove parts that change each time (like counts) so the node is still found next time.

Wait & detect notification PRO

Wait for a notification that contains the text you chose, read it aloud, then continue the script.

  1. Tap “Add action”, choose Wait & detect notification
  2. Tap “Pick a sample notification”, choose a notification
  3. Enter the words the notification must contain
  4. Tap “Use this sample”
  5. Add a Click step on “Confirm order”
  6. Go back, tap Test run, then open the app
  7. When a customer orders…

▶ AutoGest reads the notification aloud, then confirms

Tips
  • Pick a real notification as the sample and tap the words to wait for; parts that change (like the order number) are matched loosely.
  • A script that only waits for notifications can run in the background, even with the screen off.
  • Notification content stays on your phone and is never written to the log.

If… then PRO

Run some steps only when a condition is true — an image, a color, some text, the round number or a variable.

  1. Tap “Add action”, choose If… then
  2. Choose “Text”, enter the text to look for
  3. Turn off the Else branch, tap “Done”
  4. Add to the Then branch: Click the close (✕) button
  5. Go back, tap Test run, then open the app

▶ AutoGest sees “Advertisement”, so it taps close

Tips
  • Turn on the Else branch to run other steps when the condition is false.
  • Blocks are one level only; to nest logic, split it into another script and use Call script.

Repeat until PRO

Repeat the steps inside the block until a condition becomes true, or a set number of rounds.

  1. Tap “Add action”, choose Repeat until
  2. Stop on “Text”: enter the text shown when done
  3. Add to the loop: Click “Load more”
  4. Go back, tap Test run, then open the app

▶ AutoGest taps “Load more” until “No more stories” shows

Tips
  • Always set a maximum number of rounds so the script cannot run forever by mistake.

Stop script PRO

End the whole run when a condition is met — for example when you run out of turns or energy.

  1. Add a Click step on “Spin”
  2. Go back, add Stop script
  3. Stop when the text “Out of spins” is on screen
  4. Repeat the script without limit
  5. Tap Test run, then open the app

▶ After the last spin, AutoGest stops by itself

Tips
  • With an unlimited loop, this is the clean way to finish.
  • Placed inside an If… then branch, it can stop right away without a condition.

Next loop PRO

Skip the rest of this round and start the next one when a condition is met.

  1. Add a Click step on “Next post”
  2. Add Next loop when “Sponsored” is on screen
  3. Add a Click step on “Like”
  4. Repeat the script 4 times
  5. Tap Test run, then open the app

▶ AutoGest likes posts 1 and 3 and skips the sponsored ones

Tips
  • Handy to skip ads or items you do not want while going through a list.
  • It jumps to the end of the nearest loop in the same script.

Run another script, then come back — reuse steps you already built.

  1. Tap “Add action”, choose Call script
  2. Tap “Pick script”, choose the script to call
  3. Choose how many times to call it
  4. Tap Test run, then open the app

▶ AutoGest runs “Tap the button” 3 times

Tips
  • Choose how many times to call it in a row.
  • The called script runs with this script’s rhythm settings.

Set variable PRO

Set a variable to a value, or add a number to it — counters, running totals, remembered text.

  1. Tap “Add action”, choose Set variable
  2. Name the new variable, tap “Add variable”
  3. Make the step add 1 to the variable
  4. Add Paste text into the chat field: “Message #” + the variable
  5. Add a Click step on “Send”
  6. Repeat the script 3 times
  7. Tap Test run, then open the app

▶ Each round the number goes up: 1, 2, 3

Tips
  • Insert {name} in any text field to use the variable’s value.
  • Variables only live during one run: press Stop and they reset.
