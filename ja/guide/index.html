タップ

最も基本的なアクション：画面上で選んだ位置を AutoGest が正確にタップします。

  1. 「アクションを追加」をタップし、タップを選ぶ
  2. 「位置を追加」をタップ
  3. アプリを開き、照準をその位置へドラッグ
  4. OK をタップして座標を保存
  5. AutoGest に戻ると座標が入っている
  6. テスト実行をタップしてアプリを開く

▶ AutoGest が選んだ位置を正確にタップ

ヒント
  • 座標は画面サイズに合わせて換算されるので、画面サイズの違う端末でも正しい位置をタップします。
  • 共通設定でステップ間の休みと、必要ならタップ位置の小さなずれを設定できます。
  • ボタンの位置が変わる？ 画像をタップ、文字をタップ(OCR)、文字をタップで先にボタンを探させましょう。

連続タップ

一点を毎秒 1〜20 回の速さで連続タップ。何度も押す必要があるボタンに。

  1. 「アクションを追加」をタップし、連続タップを選ぶ
  2. 「位置を追加」をタップ
  3. アプリを開き、照準をボタンに合わせる
  4. OK をタップして座標を保存
  5. AutoGest に戻り、タップ回数を減らす
  6. テスト実行をタップしてアプリを開く

▶ AutoGest が 30 回、毎秒 10 回タップ

ヒント
  • 回数、時間で止めるか、停止を押すまで続けるかを選べます。
  • 毎秒 10 回を超えると、アプリによっては処理が追いつかずタップが抜けることがあります。その場合は速度を下げてください。

長押し

選んだ時間だけ一点を長押し。長押しで確定するボタン、コンテキストメニュー、ドラッグ選択に。

  1. 「アクションを追加」をタップし、長押しを選ぶ
  2. 「位置を追加」をタップ
  3. アプリを開き、照準をボタンに合わせる
  4. OK をタップして座標を保存
  5. AutoGest に戻り、長押しの時間を選ぶ
  6. テスト実行をタップしてアプリを開く

▶ AutoGest がボタンを 2 秒長押しし、ロック解除

ヒント
  • 「長押しで確定」ボタンには、アプリが求める時間より少し長めに設定しましょう。

スワイプ

  1. 「アクションを追加」をタップし、スワイプを選ぶ
  2. 開始位置を選ぶ
  3. 戻って終了位置を選ぶ
  4. 戻ってスワイプの時間を選ぶ
  5. テスト実行をタップしてアプリを開く

▶ AutoGest が開始位置から終了位置へスワイプ

ヒント
  • 短い時間は素早いフリック、長い時間はゆっくりしたドラッグ（ドラッグ＆ドロップ、スライダー）になります。

文字を入力 PRO

キーボードで押したキーを一つずつ記録し、実行時に AutoGest が同じキーをもう一度押します。

  1. 「アクションを追加」をタップし、文字を入力を選ぶ
  2. キー記録欄をタップし、キーボードで入力
  3. 「完了」をタップしてキーを保存
  4. 入力先の欄を選ぶ（任意）
  5. 戻ってテスト実行をタップし、アプリを開く

▶ AutoGest が欄をタップし、キーを一つずつ再現

ヒント
  • AutoGest はキーの位置で押すため、記録と実行で同じキーボード（同じ種類の入力欄）を使ってください。
  • 入力後に AutoGest が欄を確認し、文字が一致しなければエラーにして入力を止めます。
  • 一つずつ押す必要がなければ、カードをテキストを貼り付けに切り替えられます。

待機

次のステップの前に一時停止。画面の読み込み、アニメーションの終了、タイマーの経過を待ちます。

  1. 「アクションを追加」をタップし、待機を選ぶ
  2. 待ち時間（ms）を入力
  3. タップ ステップを追加して間隔を見る
  4. 「共通設定」でスクリプトを 2 回繰り返す
  5. テスト実行をタップしてアプリを開く

▶ タップの間隔は 3 秒＋ステップ間の休み

ヒント
  • 各ステップはすでに短い休みを入れています（共通設定で設定）。もっと長く待ちたいときだけ追加しましょう。
  • 何かが表示されるのを待つなら、画像を待機、文字を待機(OCR)、色を待機なら表示された瞬間に進みます。

画像を待機 PRO

画面に画像が現れる（または消える）までタップせずに待ち、そのあと次のステップへ進みます。

  1. 「アクションを追加」をタップし、画像を待機を選ぶ
  2. 「画像を選択」をタップし、「画面から切り取る」を選ぶ
  3. 画面を開き、キャプチャをタップして画像を囲む
  4. 戻って、画像が出る位置に タップ を追加
  5. 戻ってテスト実行をタップし、アプリを開く

▶ AutoGest が郵便受けを待ってから タップ を実行

ヒント
  • 探したいものにぴったり合わせて切り取り、変わる背景を含めないようにしましょう。
  • 毎回少し見た目が違うなら、最小一致度を下げてください。

色を待機 PRO

一点が選んだ色になる（または色が変わる）まで監視。信号が青になる、ボタンが有効になる、など。

  1. 「アクションを追加」をタップし、色を待機を選ぶ
  2. 「位置を追加」をタップ、色を待つ位置に照準を合わせる
  3. 戻る：AutoGest がその位置の色を読み取り済み
  4. 「進む」にタップステップを追加
  5. 戻ってテスト実行をタップし、アプリを開く

▶ AutoGest が青信号を待ってから「進む」をタップ

ヒント
  • 待ちたい色が表示されているときに位置を選べば、AutoGest が色を読み取ります。
  • 画面の画像だけを見るので、アプリが文字や要素を公開していない場所でも使えます。

文字をタップ(OCR) PRO

端末上の文字認識（OCR）でスクリーンショットの文字を読み取り、タップします。アプリが画像として描画した文字も見つけられます。

  1. 「アクションを追加」をタップし、文字をタップ(OCR)を選ぶ
  2. ボタンの文字を入力
  3. テスト実行をタップしてアプリを開く

▶ AutoGest が画面の画像を読み取り、文字をタップ

ヒント
  • 日本語の文字は「日本語」の文字種を選んでください。英語などは Latin で読み取れます。
  • 検索範囲を狭めると、より速く正確に読み取れます。
  • 認識は端末内で行われ、どこにも送信されません。

文字を読み取り(OCR) PRO

画面の画像の一部分の文字を読み取り、変数に保存して後のステップで使います。

  1. 「アクションを追加」をタップし、文字を読み取り(OCR)を選ぶ
  2. 「範囲を選択」をタップし、画面を開いてキャプチャ
  3. 番号を囲んで OK
  4. 戻って「数字のみ」と保存先の変数を選ぶ
  5. 入力欄にテキストを貼り付けを追加し、変数を挿入
  6. 「検索」にタップステップを追加

▶ AutoGest が画像から注文番号を読み取って入力

ヒント
  • 「数字のみ」を選ぶと数字だけを残せます。価格、合計、注文番号に。
  • 変数はテキスト貼り付けで使ったり、もし…ならばブロックで比較したりできます。

もし… なら PRO

条件を満たすときだけステップを実行。条件は画像、色、文字、周回数、変数から選べます。

  1. 「アクションを追加」をタップし、もし… ならを選ぶ
  2. 「文字」を選び、探す文字を入力
  3. 「それ以外」の分岐をオフにし、「完了」
  4. 「ならば」分岐に追加：閉じる（✕）ボタンを タップ
  5. 戻ってテスト実行をタップし、アプリを開く

▶ AutoGest が「新機能」を見つけて閉じるをタップ

ヒント
  • 「それ以外」の分岐をオンにすると、条件を満たさないときに別のステップを実行できます。
  • ブロックは一階層だけです。入れ子にしたい場合は別のスクリプトに分けてスクリプトを呼び出すを使いましょう。

条件まで繰り返す PRO

条件を満たすまで、または指定回数だけ、ブロック内のステップを繰り返します。

  1. 「アクションを追加」をタップし、条件まで繰り返すを選ぶ
  2. 「文字」で停止：終わりに出る文字を入力
  3. ループに追加：「もっと読み込む」を タップ
  4. 戻ってテスト実行をタップし、アプリを開く

▶ AutoGest が「これ以上ニュースはありません」が出るまで「もっと読み込む」をタップ

ヒント
  • 誤って無限に動かないよう、必ず最大周回数を設定しましょう。

スクリプトを停止 PRO

条件を満たしたら実行全体を終了。リストが最後まで来たときや、作業の完了が表示されたときなどに。

  1. 「完了にする」にタップステップを追加
  2. 戻ってスクリプトを停止を追加
  3. 「すべて完了」の文字が出たら停止
  4. スクリプトを無制限に繰り返す
  5. テスト実行をタップしてアプリを開く

▶ 最後のタスクのあと、AutoGest が自動で停止

ヒント
  • スクリプトを無制限に繰り返すときの、きれいな終わらせ方です。
  • もし…ならばの分岐内に置けば、条件なしですぐ止められます。

次の回へ PRO

条件を満たしたら、この周回の残りを飛ばして次の周回へ進みます。

  1. 「次の注文」にタップステップを追加
  2. 「キャンセル済み」が出たら次の回へを追加
  3. 「確認」にタップステップを追加
  4. スクリプトを 4 回繰り返す
  5. テスト実行をタップしてアプリを開く

▶ AutoGest は注文 1 と 2 を確認し、キャンセル済みは飛ばす

ヒント
  • リストを順に処理するとき、不要な項目を飛ばすのに便利です。
  • 同じスクリプト内で一番近いループの終わりへジャンプします。

スクリプトを呼び出す PRO

別のスクリプトを実行して戻ってきます。作ったステップを再利用できます。

  1. 「アクションを追加」をタップし、スクリプトを呼び出すを選ぶ
  2. 「スクリプトを選択」をタップし、呼び出すスクリプトを選ぶ
  3. 呼び出す回数を選ぶ
  4. テスト実行をタップしてアプリを開く

▶ AutoGest が「ボタンをタップ」を 3 回実行

ヒント
  • 続けて呼び出す回数を選べます。
  • 呼び出されたスクリプトは、このスクリプトのリズム設定で動きます。

変数に書き込む PRO

変数に値を設定、または数を足します。カウンター、累計、覚えておく文字に。

  1. 「アクションを追加」をタップし、変数に書き込むを選ぶ
  2. 新しい変数に名前を付け、「変数を追加」
  3. ステップで変数に 1 を足す
  4. リストの入力欄にテキストを貼り付け：「項目 #」＋変数
  5. 「追加」にタップステップを追加
  6. スクリプトを 3 回繰り返す
  7. テスト実行をタップしてアプリを開く

▶ 回ごとに数字が増える：1、2、3

ヒント
  • 任意の文字入力欄に {名前} を挿入すると変数の値を使えます。
  • 変数は一回の実行中だけ有効で、停止するとリセットされます。
