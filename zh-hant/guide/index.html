輕觸

最基本的動作：AutoGest 精準點擊你在螢幕上選的位置。

  1. 點選「新增動作」，選擇輕觸
  2. 點選「新增位置」
  3. 開啟應用程式，把準星拖到要點的位置
  4. 點選 OK 儲存座標
  5. 回到 AutoGest，座標已填好
  6. 點選試執行，再開啟應用程式

▶ AutoGest 精準點擊所選位置

小技巧
  • 座標會依螢幕尺寸換算，換到螢幕不同的手機上也能點準。
  • 在通用設定設定步驟間的停頓，也可以給點擊加一點偏移。
  • 按鈕位置會變？用輕觸圖片、輕觸文字(OCR)或輕觸文字讓 AutoGest 先找到它。

連續輕觸

以每秒 1 到 20 次的速度連續點擊同一位置，適合需要按很多次的按鈕。

  1. 點選「新增動作」，選擇連續輕觸
  2. 點選「新增位置」
  3. 開啟應用程式，把準星放在按鈕上
  4. 點選 OK 儲存座標
  5. 回到 AutoGest，減少點擊次數
  6. 點選試執行，再開啟應用程式

▶ AutoGest 點擊 30 次，每秒 10 次

小技巧
  • 可以依次數、依時間停止，或一直點到你按停止。
  • 每秒超過 10 次時，有些應用程式跟不上，可能漏掉點擊；這時請降低速度。

長按

按住一個位置，時間由你決定——用於長按確認按鈕、內容選單、拖曳選取。

  1. 點選「新增動作」，選擇長按
  2. 點選「新增位置」
  3. 開啟應用程式，把準星放在按鈕上
  4. 點選 OK 儲存座標
  5. 回到 AutoGest，選擇長按時間
  6. 點選試執行，再開啟應用程式

▶ AutoGest 長按按鈕 2 秒，成功解鎖

小技巧
  • 「長按確認」的按鈕，時間設得比應用程式要求的稍長一點。

滑動

手指從起點拖到終點——滑動解鎖、拖動滑桿、翻頁。

  1. 點選「新增動作」，選擇滑動
  2. 選擇起點
  3. 返回，選擇終點
  4. 返回，選擇滑動時間
  5. 點選試執行，再開啟應用程式

▶ AutoGest 從起點滑到終點

小技巧
  • 時間短是快速滑動，時間長是慢慢拖曳（拖放、滑桿）。

沿路徑拖曳

長按拿起項目，沿你手繪的路徑原樣拖曳（曲線、波浪、中途停頓都會重現），放開手指即放下。

  1. 點選「新增動作」，選擇沿路徑拖曳
  2. 點選「繪製」，開啟有卡片的應用程式
  3. 點選面板上的「繪製」，按住卡片片刻，畫出到「已完成」的路徑後放開
  4. 點選 OK 儲存路徑
  5. 回到 AutoGest，步驟顯示剛畫的路徑
  6. 點選試執行，再開啟應用程式

▶ AutoGest 按住卡片，沿同一路徑拖曳，放進「已完成」

小技巧
  • 如果應用程式需要長按才能拿起項目（圖示、卡片、清單列），畫的時候先在起點停住手指片刻。
  • 畫路徑時，下方的應用程式收不到你的觸控，所以還不會真的移動任何東西。
  • AutoGest 拖曳時請勿觸碰螢幕：系統會取消這次拖曳。
  • 只需從一點直線拖到另一點？請用滑動。

捲動

在螢幕中間滑一下，把列表往上、下、左、右捲動——不必選座標。

  1. 點選「新增動作」，選擇捲動
  2. 選擇方向和時間
  3. 點選試執行，再開啟應用程式

▶ AutoGest 在螢幕中間滑動來捲動

小技巧
  • 搭配重複直到，可以一直捲動到出現你要找的內容。

雙指手勢

兩根手指圍繞一個點張開、捏合或轉動——用來放大、縮小或旋轉地圖和照片。

  1. 點選「新增動作」，選擇雙指手勢
  2. 點選「新增位置」，對準地圖中央，點選 OK
  3. 回到 AutoGest：預設為「放大」「中」
  4. 在同一位置新增第二個步驟
  5. 返回，選擇「縮小」
  6. 第三個步驟也加在地圖中央
  7. 返回，選擇「旋轉」（順時針）
  8. 點選試執行，再開啟應用程式

▶ AutoGest 先放大、再縮小，然後旋轉地圖

小技巧
  • 小 / 中 / 大約放大 ×1.5 / ×2 / ×3，或旋轉 30° / 90° / 180°。
  • 手勢太快時，有些應用程式在手指離開後還會繼續滑動；設為 1000ms 結果更穩定。
  • 錄製功能暫時無法錄下雙指手勢：請手動新增這個步驟。

貼上文字

點選輸入框，把準備好的整段文字填進去——又快，字元也不會出錯。

  1. 點選「新增動作」，選擇貼上文字
  2. 點選「新增位置」，對準輸入框
  3. 返回，輸入要貼上的內容
  4. 點選試執行，再開啟應用程式

▶ AutoGest 把整段文字貼進輸入框

小技巧
  • 用插入變數插入變數，可貼上本次執行中先前讀到的值。
  • 應用程式禁止貼上？用逐鍵輸入逐一點按鍵盤上的按鍵。

逐鍵輸入 PRO

錄下你在鍵盤上按的每個鍵；執行時 AutoGest 按同樣的鍵。

  1. 點選「新增動作」，選擇逐鍵輸入
  2. 點選按鍵錄製框，在鍵盤上輸入
  3. 點選「完成」儲存按鍵
  4. 選擇要輸入的欄位（選用）
  5. 返回，點選試執行，再開啟應用程式

▶ AutoGest 點選欄位，再逐一重播按鍵

小技巧
  • AutoGest 依按鍵位置點按，錄製和執行時請使用同一個鍵盤（以及同類輸入框）。
  • 輸入後 AutoGest 會檢查欄位，文字不符就回報錯誤並停止輸入。
  • 不需要逐鍵輸入？把卡片切換為貼上文字。

等待

在下一步前停一下——等畫面載入、動畫結束或計時器走完。

  1. 點選「新增動作」，選擇等待
  2. 輸入等待時間（毫秒）
  3. 新增一個 輕觸 步驟來看停頓
  4. 在「通用設定」把腳本重複 2 次
  5. 點選試執行，再開啟應用程式

▶ 兩次點擊相隔 3 秒，再加上步驟間的停頓

小技巧
  • 每一步本來就會停頓一小段時間（在通用設定設定）；只有需要更久時才加等待。
  • 在等某樣東西出現？等待圖片、等待文字(OCR)或等待顏色一出現就繼續。

等待圖片 PRO

不點擊，等到螢幕上出現（或消失）某張圖片，再執行後面的步驟。

  1. 點選「新增動作」，選擇等待圖片
  2. 點選「選取圖片」，選擇「從螢幕裁剪」
  3. 開啟畫面，點選擷取，框住圖片
  4. 返回，在圖片出現的位置新增 輕觸
  5. 返回，點選試執行，再開啟應用程式

▶ AutoGest 等信箱出現後才執行 輕觸

小技巧
  • 把圖片裁得緊貼目標，不要包含會變化的背景。
  • 如果圖片每次略有不同，調低最低相符度。

等待顏色 PRO

盯住一個點，直到它變成指定顏色（或改變顏色）——例如紅綠燈變綠、按鈕變成可用。

  1. 點選「新增動作」，選擇等待顏色
  2. 點選「新增位置」，對準要等顏色的位置
  3. 返回：AutoGest 已讀出該處顏色
  4. 在「出發」新增輕觸步驟
  5. 返回，點選試執行，再開啟應用程式

▶ AutoGest 等到綠燈才點「出發」

小技巧
  • 在螢幕顯示目標顏色時選點，AutoGest 會幫你讀出顏色。
  • 只看螢幕影像，所以在應用程式沒有公開文字或元素的地方也能用。

↑ 回到動作列表

輕觸圖片 PRO

在螢幕上找到一張圖片並點擊，不管它在哪——最適合會移動的按鈕。

  1. 點選「新增動作」，選擇輕觸圖片
  2. 點選「選取圖片」，選擇「從螢幕裁剪」
  3. 開啟有圖片的畫面，點選擷取
  4. 把框貼齊圖片，點選 OK
  5. 返回，點選試執行，再開啟應用程式

▶ AutoGest 等信箱出現後點擊它

小技巧
  • AutoGest 看的是螢幕影像而不是應用程式結構，所以沒有文字的按鈕也找得到。
  • 只裁按鈕本身，不要帶到周圍的背景。

↑ 回到動作列表

輕觸文字(OCR) PRO

用手機本機的文字辨識（OCR）讀取螢幕截圖裡的文字並點擊——應用程式以圖像繪製的文字也找得到。

  1. 點選「新增動作」，選擇輕觸文字(OCR)
  2. 輸入按鈕上的文字
  3. 點選試執行，再開啟應用程式

▶ AutoGest 讀取螢幕影像並點擊文字

小技巧
  • 中文請選「中文」字元集；英文等使用 Latin 即可。
  • 縮小搜尋範圍，讀得更快更準。
  • 辨識在手機本機完成，不會傳送到任何地方。

↑ 回到動作列表

等待文字(OCR) PRO

不點擊，等到螢幕影像上出現（或消失）某段文字。

  1. 點選「新增動作」，選擇等待文字(OCR)
  2. 輸入要等待的文字
  3. 在「分享連結」新增輕觸步驟
  4. 返回，點選試執行，再開啟應用程式

▶ AutoGest 等到「已完成」才點「分享連結」

小技巧
  • 適合「上傳完成」「已儲存」或倒數結束這類提示。
  • 選定範圍可以更快等到，也不會誤認別處的相同文字。

↑ 回到動作列表

辨識文字(OCR) PRO

讀取螢幕影像某個範圍內的文字，存進變數供後面的步驟使用。

  1. 點選「新增動作」，選擇辨識文字(OCR)
  2. 點選「選擇區域」，開啟畫面，點選擷取
  3. 框住訂單編號，點選 OK
  4. 返回，選擇「只取數字」和要儲存的變數
  5. 在輸入框新增貼上文字，插入變數
  6. 在「查詢」新增輕觸步驟
  7. 點選試執行，再開啟應用程式

▶ AutoGest 從影像讀出訂單編號並填入

小技巧
  • 選「只取數字」只保留數字——價格、合計或訂單編號。
  • 變數可用於貼上文字，或在如果…則區塊中比較。

輕觸文字

輸入按鈕上顯示的文字；執行時 AutoGest 在螢幕上找到這段文字並點擊。

  1. 點選「新增動作」，選擇輕觸文字
  2. 輸入按鈕上顯示的文字
  3. 點選試執行，再開啟應用程式

▶ 不管按鈕在哪裡，AutoGest 都能找到文字並點擊

小技巧
  • 它讀取應用程式結構，所以看不到以圖像繪製的文字——這時請用輕觸文字(OCR)。
  • 不分大小寫，只要包含你輸入的文字即可。

↑ 回到動作列表

輕觸節點 PRO

擷取螢幕、點選一個元素，AutoGest 就會記住如何再次找到它——只有圖示的按鈕也可以。

  1. 點選「新增動作」，選擇輕觸節點
  2. 點選「選取節點」，開啟應用程式，點選擷取
  3. 點選要按的按鈕，再點「選取節點」
  4. 返回，選擇尋找節點的方式
  5. 點選試執行，再開啟應用程式

▶ AutoGest 找到燈開關並點擊

小技巧
  • text 或 content-desc 不變時就用它們尋找；應用程式更新會變的 resource-id 盡量避免。
  • 刪掉每次都會變的部分（例如計數），下次也能找到。

↑ 回到動作列表

讀取螢幕文字 PRO

選螢幕上的一個元素，不點擊，把它的文字複製到變數。

  1. 點選「新增動作」，選擇讀取螢幕文字
  2. 點選「選取節點」，開啟應用程式，點選擷取
  3. 點選訂單編號，再點「選取節點」
  4. 返回，選擇要儲存的變數
  5. 在輸入框新增貼上文字，插入變數
  6. 在「查詢」新增輕觸步驟
  7. 點選試執行，再開啟應用程式

▶ AutoGest 複製訂單編號並填入

小技巧
  • 適合取得應用程式裡顯示的訂單編號、價格或參考編號。
  • 它讀取應用程式結構；以圖像繪製的文字請用辨識文字(OCR)。

等待並辨識通知 PRO

等待包含你所選文字的通知，朗讀出來，然後繼續執行腳本。

  1. 點選「新增動作」，選擇等待並辨識通知
  2. 點選「選取範本通知」，選一則通知
  3. 輸入通知必須包含的文字
  4. 點選「使用此範本」
  5. 在「確認訂單」新增輕觸步驟
  6. 返回，點選試執行，再開啟應用程式
  7. 有顧客下單時…

▶ AutoGest 朗讀通知後點確認

小技巧
  • 選一則真實通知當樣本，輸入要等的文字；每次會變的部分（如訂單編號）會寬鬆比對。

如果… 就 PRO

停止腳本 PRO

條件符合時結束整次執行——例如清單到底或工作提示已完成時。

寫入變數 PRO

給變數設定值或加上一個數——計數器、累計總數、需要記住的文字。

  1. 點選「新增動作」，選擇寫入變數
  2. 為新變數命名，點選「新增變數」
  3. 讓步驟為變數加 1
  4. 在清單輸入框新增貼上文字：「項目 #」＋變數
  5. 在「新增」新增輕觸步驟
  6. 腳本重複 3 次
  7. 點選試執行，再開啟應用程式

▶ 每一輪數字遞增：1、2、3

小技巧
  • 在任何文字輸入框插入 {名稱} 即可使用變數的值。
  • 變數只在一次執行中有效：按停止就會清空。
