Let your phone repeat the boring taps

AutoGest is an Android app that runs automation scripts you build or record yourself: taps, swipes, typing, opening apps — replayed with a natural, human-like rhythm.

What you can do

Build scripts step by step Tap, long press, swipe, scroll, paste or type text, wait, press Back / Home / Recent apps, or open an app. Pick each point right on the screen.
Record instead of building Do the task once while recording, review the captured steps, keep the ones you want.
React to what is on screen Tap an image or a piece of text when it appears — even in games, with on-device text recognition — wait for a color, and use If… then, Repeat until, Stop script and Next loop.
Remember values Read text or numbers from the screen or a notification into variables, count rounds, and paste the values back.
Run on your terms Start from the app, a home-screen shortcut, a schedule or an incoming notification; pause and stop from the floating bubble or the notification.
Share scripts Export a script as an .autoscript file and import scripts others send you.

Privacy

The app has no Internet permission, no accounts, no ads and no analytics. The Accessibility service is used only to record and run the scripts you create, and everything you create stays on your phone.
