Guide d’utilisation

Chaque action a une courte vidéo filmée sur un vrai téléphone, avec une appli d’exemple pour voir le résultat. Chaque appui s’illumine pour être facile à suivre. Les actions marquées PRO font partie d’AutoGest Pro.

  • Vous appuyez
  • AutoGest appuie tout seul pendant le script

Appuyer

L’action la plus simple : AutoGest appuie exactement sur le point que vous avez choisi à l’écran.

  1. Appuyez sur « Ajouter une action », choisissez Appuyer
  2. Appuyez sur « Ajouter un point »
  3. Ouvrez l’appli, faites glisser le viseur sur le point
  4. Appuyez sur OK pour enregistrer le point
  5. De retour dans AutoGest, le point est rempli
  6. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest appuie exactement sur le point choisi

Astuces
  • Les points sont adaptés à la taille de l’écran : le script vise juste aussi sur un téléphone à l’écran différent.
  • Dans Paramètres généraux, réglez la pause entre étapes et un léger décalage d’appui, pour un geste naturel.
  • Le bouton change de place ? Utilisez Appuyer sur une image, Appuyer sur un texte (OCR) ou Appuyer sur un texte pour qu’AutoGest le trouve d’abord.

Appuis rapides

Appuyez sur un point encore et encore, de 1 à 20 fois par seconde — idéal pour les jeux qui demandent des appuis rapides.

  1. Appuyez sur « Ajouter une action », choisissez Appuis rapides
  2. Appuyez sur « Ajouter un point »
  3. Ouvrez l’appli, placez le viseur sur le bouton
  4. Appuyez sur OK pour enregistrer le point
  5. De retour dans AutoGest, réduisez le nombre d’appuis
  6. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest appuie 30 fois, 10 appuis par seconde

Astuces
  • Arrêtez après un nombre d’appuis, après une durée, ou continuez jusqu’à ce que vous appuyiez sur Arrêter.
  • Plus de 10 appuis par seconde dépasse une main humaine ; certaines applis peuvent le trouver suspect.
  • Activez le rythme naturel pour que l’écart entre appuis varie un peu, comme un vrai doigt.

↑ Retour à la liste des actions

Appui long

Appuyez et maintenez un point aussi longtemps que voulu — boutons « maintenir pour confirmer », menus contextuels, sélection par glissement.

  1. Appuyez sur « Ajouter une action », choisissez Appui long
  2. Appuyez sur « Ajouter un point »
  3. Ouvrez l’appli, placez le viseur sur le bouton
  4. Appuyez sur OK pour enregistrer le point
  5. De retour dans AutoGest, choisissez la durée de maintien
  6. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest maintient le bouton 2 s et il se déverrouille

Astuces
  • Pour un bouton « maintenir pour confirmer », choisissez une durée un peu plus longue que celle demandée.

Balayer

Faites glisser un doigt d’un point de départ à un point d’arrivée — balayer pour déverrouiller, déplacer un curseur, tourner les pages.

  1. Appuyez sur « Ajouter une action », choisissez Balayer
  2. Choisissez le point de départ
  3. Revenez, choisissez le point d’arrivée
  4. Revenez, choisissez la durée du balayage
  5. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest balaie du point de départ au point d’arrivée

Astuces
  • Une durée courte donne un balayage rapide ; une longue, un glissement lent (glisser-déposer, curseurs).

↑ Retour à la liste des actions

Défiler

Faites défiler une liste vers le haut, le bas, la gauche ou la droite d’un balayage au milieu de l’écran — sans point à choisir.

  1. Appuyez sur « Ajouter une action », choisissez Défiler
  2. Choisissez la direction et la durée
  3. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest balaie le milieu de l’écran pour faire défiler

Astuces
  • Combinez avec Répéter jusqu’à pour défiler jusqu’à voir ce que vous cherchez.

Coller du texte

Touchez un champ de texte et remplissez-le avec tout le texte préparé — rapide, avec tous les accents.

  1. Appuyez sur « Ajouter une action », choisissez Coller du texte
  2. Appuyez sur « Ajouter un point », visez le champ de texte
  3. Revenez, saisissez le texte à coller
  4. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest colle tout le texte dans le champ

Astuces
  • Séparez plusieurs textes par || et AutoGest en choisit un au hasard à chaque exécution.
  • Insérez une variable avec Insérer une variable pour coller une valeur lue plus tôt pendant l’exécution.
  • L’appli bloque le collage ? Utilisez Saisir des caractères pour taper chaque touche comme une personne.

↑ Retour à la liste des actions

Saisir des caractères PRO

Enregistrez chaque touche tapée au clavier ; à l’exécution, AutoGest tape les mêmes touches à votre rythme.

  1. Appuyez sur « Ajouter une action », choisissez Saisir des caractères
  2. Touchez la zone d’enregistrement, tapez au clavier
  3. Appuyez sur « OK » pour garder les touches
  4. Choisissez le champ où taper (facultatif)
  5. Revenez, appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest touche le champ, puis rejoue chaque touche

Astuces
  • Utilisez le même clavier (et le même type de champ) à l’enregistrement et à l’exécution, car AutoGest tape selon la position des touches.
  • Après la saisie, AutoGest vérifie le champ ; si le texte ne correspond pas, l’étape signale une erreur et s’arrête.
  • Pas besoin de taper chaque touche ? Passez la carte en Coller du texte.

↑ Retour à la liste des actions

Attendre

Faites une pause avant l’étape suivante — laissez un écran charger, une animation finir ou un minuteur s’écouler.

  1. Appuyez sur « Ajouter une action », choisissez Attendre
  2. Saisissez le temps d’attente (ms)
  3. Ajoutez une étape Appuyer pour voir la pause
  4. Répétez le script 2 fois dans « Paramètres généraux »
  5. Appuyez sur Tester, puis ouvrez l’appli

▶ Les appuis arrivent à 3 s d’écart, plus la pause entre étapes

Astuces
  • Chaque étape attend déjà une courte pause aléatoire (réglée dans Paramètres généraux) ; ajoutez une attente seulement si vous avez besoin de plus.
  • Vous attendez qu’un élément apparaisse ? Attendre une image, Attendre un texte (OCR) ou Attendre une couleur continuent dès qu’il est là.

↑ Retour à la liste des actions

Attendre une image PRO

Attendez qu’une image apparaisse (ou disparaisse) à l’écran, sans appuyer — puis les étapes suivantes s’exécutent.

  1. Appuyez sur « Ajouter une action », choisissez Attendre une image
  2. Appuyez sur « Choisir une image », choisissez « Recadrer depuis l’écran »
  3. Ouvrez l’écran, appuyez sur Capturer, cadrez l’image
  4. Revenez, ajoutez une étape Appuyer là où l’image apparaît
  5. Revenez, appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest attend la boîte cadeau, puis exécute l’étape Appuyer

Astuces
  • Recadrez l’image au plus près de l’élément, sans fond changeant.
  • Baissez la correspondance minimale si l’image varie un peu à chaque fois.

↑ Retour à la liste des actions

Attendre une couleur PRO

Surveillez un point jusqu’à ce qu’il prenne une couleur choisie (ou change de couleur) — un feu qui passe au vert, un bouton qui s’active.

  1. Appuyez sur « Ajouter une action », choisissez Attendre une couleur
  2. Appuyez sur « Ajouter un point », visez le point de la couleur
  3. Revenez : AutoGest a lu la couleur à cet endroit
  4. Ajoutez une étape Appuyer sur « Partir »
  5. Revenez, appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest attend le feu vert, puis appuie sur « Partir »

Astuces
  • Choisissez le point quand l’écran affiche la couleur voulue : AutoGest la lit pour vous.
  • Fonctionne aussi dans les jeux, car seule l’image de l’écran compte.

↑ Retour à la liste des actions

Appuyer sur une image PRO

Trouvez une image à l’écran et appuyez dessus, où qu’elle soit — parfait pour les boutons qui bougent.

  1. Appuyez sur « Ajouter une action », choisissez Appuyer sur une image
  2. Appuyez sur « Choisir une image », choisissez « Recadrer depuis l’écran »
  3. Ouvrez l’écran avec l’image, appuyez sur Capturer
  4. Serrez le cadre autour de l’image, appuyez sur OK
  5. Revenez, appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest attend la boîte cadeau, puis appuie dessus

Astuces
  • Fonctionne dans les jeux, car AutoGest regarde l’image de l’écran et non la structure de l’appli.
  • Recadrez juste le bouton, sans le fond autour.

↑ Retour à la liste des actions

Appuyer sur un texte (OCR) PRO

Lisez le texte d’une capture grâce à la reconnaissance de texte (OCR) sur le téléphone, puis appuyez dessus — même dans les jeux qui dessinent leur texte.

  1. Appuyez sur « Ajouter une action », choisissez Appuyer sur un texte (OCR)
  2. Saisissez le texte du bouton
  3. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest lit l’image de l’écran — même dans les jeux — et appuie sur le texte

Astuces
  • Choisissez la bonne écriture pour le chinois, le japonais ou le coréen ; Latin couvre le français, l’anglais, l’espagnol et d’autres.
  • Réduisez la zone de recherche pour lire plus vite et plus juste.
  • La reconnaissance se fait sur votre téléphone ; rien n’est envoyé.

↑ Retour à la liste des actions

Attendre un texte (OCR) PRO

Attendez qu’un texte apparaisse (ou disparaisse) sur l’image de l’écran, sans appuyer.

  1. Appuyez sur « Ajouter une action », choisissez Attendre un texte (OCR)
  2. Saisissez le texte à attendre
  3. Ajoutez une étape Appuyer sur « Courir »
  4. Revenez, appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest attend « PARTEZ », puis appuie sur « Courir »

Astuces
  • Pratique pour les écrans de jeu comme « Prêts… Partez ! », « Victoire » ou la fin d’un compte à rebours.
  • Choisissez une zone pour attendre plus vite et éviter le même mot ailleurs.

↑ Retour à la liste des actions

Lire un texte (OCR) PRO

Lisez le texte d’une zone de l’image de l’écran et enregistrez-le dans une variable pour la suite.

  1. Appuyez sur « Ajouter une action », choisissez Lire un texte (OCR)
  2. Appuyez sur « Choisir la zone », ouvrez l’écran, appuyez sur Capturer
  3. Cadrez le code, appuyez sur OK
  4. Revenez, choisissez « Le nombre seul » et une variable où l’enregistrer
  5. Ajoutez Coller du texte dans le champ, insérez la variable
  6. Ajoutez une étape Appuyer sur « Valider »
  7. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest lit le code sur l’image et le saisit

Astuces
  • Choisissez « Le nombre seul » pour ne garder que les chiffres — scores, prix ou codes.
  • Utilisez la variable dans Coller du texte, ou comparez-la dans un bloc Si… alors.

↑ Retour à la liste des actions

Appuyer sur un texte

Saisissez le texte affiché sur un bouton ; à l’exécution, AutoGest trouve ce texte à l’écran et appuie dessus.

  1. Appuyez sur « Ajouter une action », choisissez Appuyer sur un texte
  2. Saisissez le texte affiché sur le bouton
  3. Appuyez sur Tester, puis ouvrez l’appli

▶ Où que soit le bouton, AutoGest trouve le texte et appuie

Astuces
  • Il lit la structure de l’appli, donc pas les jeux qui dessinent leur texte — utilisez alors Appuyer sur un texte (OCR).
  • Majuscules et minuscules n’importent pas, et il suffit que le texte contienne ce que vous avez saisi.

↑ Retour à la liste des actions

Appuyer sur un nœud PRO

Capturez l’écran, touchez un élément, et AutoGest retient comment le retrouver — même les boutons à icône seule.

  1. Appuyez sur « Ajouter une action », choisissez Appuyer sur un nœud
  2. Appuyez sur « Choisir un nœud », ouvrez l’appli, appuyez sur Capturer
  3. Touchez le bouton voulu, puis « Choisir ce nœud »
  4. Revenez, choisissez comment retrouver le nœud
  5. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest trouve le bouton cœur et appuie dessus

Astuces
  • Cherchez par text ou content-desc s’ils ne changent pas ; évitez resource-id si l’appli le change d’une version à l’autre.
  • Retirez les parties qui changent (comme les compteurs) pour le retrouver la prochaine fois.

↑ Retour à la liste des actions

Lire un texte à l’écran PRO

Choisissez un élément à l’écran et copiez son texte dans une variable, sans appuyer.

  1. Appuyez sur « Ajouter une action », choisissez Lire un texte à l’écran
  2. Appuyez sur « Choisir un nœud », ouvrez l’appli, appuyez sur Capturer
  3. Touchez le code, puis « Choisir ce nœud »
  4. Revenez, choisissez une variable où l’enregistrer
  5. Ajoutez Coller du texte dans le champ, insérez la variable
  6. Ajoutez une étape Appuyer sur « Valider »
  7. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest copie le code et le saisit

Astuces
  • Idéal pour les codes à usage unique, les numéros de commande ou les soldes affichés.
  • Il lit la structure de l’appli ; pour les jeux, utilisez Lire un texte (OCR).

↑ Retour à la liste des actions

Attendre et détecter une notification PRO

Attendez une notification contenant le texte choisi, lisez-la à voix haute, puis poursuivez le script.

  1. Appuyez sur « Ajouter une action », choisissez Attendre et détecter une notification
  2. Appuyez sur « Choisir une notification modèle », choisissez une notification
  3. Saisissez les mots que doit contenir la notification
  4. Appuyez sur « Utiliser ce modèle »
  5. Ajoutez une étape Appuyer sur « Confirmer la commande »
  6. Revenez, appuyez sur Tester, puis ouvrez l’appli
  7. Quand un client commande…

▶ AutoGest lit la notification à voix haute, puis confirme

Astuces
  • Prenez une vraie notification comme modèle et touchez les mots à attendre ; les parties qui changent (comme le numéro de commande) sont comparées avec souplesse.
  • Un script qui n’attend que des notifications peut tourner en arrière-plan, même écran éteint.
  • Le contenu des notifications reste sur votre téléphone et n’est jamais écrit dans le journal.

Ouvrir une appli

Ouvrez une appli de la liste et attendez qu’elle s’affiche — une bonne première étape pour tout script.

  1. Appuyez sur « Ajouter une action », choisissez Ouvrir une appli
  2. Appuyez sur « Choisir une appli », choisissez l’appli à ouvrir
  3. Appuyez sur Tester, inutile d’ouvrir l’appli vous-même

▶ AutoGest ouvre seul l’appli choisie

Astuces
  • Le script peut démarrer depuis AutoGest ; cette étape met la bonne appli au premier plan.

Si… alors PRO

N’exécutez certaines étapes que si une condition est vraie — une image, une couleur, un texte, le numéro de tour ou une variable.

  1. Appuyez sur « Ajouter une action », choisissez Si… alors
  2. Choisissez « Texte », saisissez le texte à repérer
  3. Désactivez la branche « Sinon », appuyez sur « OK »
  4. Ajoutez à la branche « Alors » : étape Appuyer sur le bouton fermer (✕)
  5. Revenez, appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest voit « Publicité » et appuie sur fermer

Astuces
  • Activez la branche Sinon pour exécuter d’autres étapes quand la condition est fausse.
  • Les blocs n’ont qu’un niveau ; pour imbriquer, séparez dans un autre script et utilisez Appeler un script.

↑ Retour à la liste des actions

Répéter jusqu’à PRO

Répétez les étapes du bloc jusqu’à ce qu’une condition soit vraie, ou un nombre de tours donné.

  1. Appuyez sur « Ajouter une action », choisissez Répéter jusqu’à
  2. Arrêt sur « Texte » : saisissez le texte affiché à la fin
  3. Ajoutez à la boucle : étape Appuyer sur « Charger plus »
  4. Revenez, appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest appuie sur « Charger plus » jusqu’à voir « Plus d’articles »

Astuces
  • Fixez toujours un nombre maximal de tours pour éviter une boucle sans fin par erreur.

↑ Retour à la liste des actions

Arrêter le script PRO

Terminez toute l’exécution quand une condition est remplie — par exemple plus de tours ou d’énergie.

  1. Ajoutez une étape Appuyer sur « Tourner »
  2. Revenez, ajoutez Arrêter le script
  3. Arrêter quand le texte « Plus de tours » s’affiche
  4. Répétez le script sans limite
  5. Appuyez sur Tester, puis ouvrez l’appli

▶ Après le dernier tour, AutoGest s’arrête tout seul

Astuces
  • Avec une boucle sans limite, c’est la façon propre de finir.
  • Placée dans une branche de Si… alors, elle peut arrêter tout de suite, sans condition.

↑ Retour à la liste des actions

Tour suivant PRO

Sautez le reste de ce tour et commencez le suivant quand une condition est remplie.

  1. Ajoutez une étape Appuyer sur « Suivant »
  2. Ajoutez Tour suivant quand « Sponsorisé » s’affiche
  3. Ajoutez une étape Appuyer sur « J’aime »
  4. Répétez le script 4 fois
  5. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest aime les publications 1 et 3 et saute les sponsorisées

Astuces
  • Pratique pour sauter les pubs ou les éléments inutiles en parcourant une liste.
  • Elle saute à la fin de la boucle la plus proche du même script.

↑ Retour à la liste des actions

Appeler un script PRO

Lancez un autre script puis revenez — réutilisez les étapes déjà créées.

  1. Appuyez sur « Ajouter une action », choisissez Appeler un script
  2. Appuyez sur « Choisir un script », choisissez le script à appeler
  3. Choisissez combien de fois l’appeler
  4. Appuyez sur Tester, puis ouvrez l’appli

▶ AutoGest lance « Appuyer sur le bouton » 3 fois

Astuces
  • Choisissez combien de fois l’appeler à la suite.
  • Le script appelé suit le rythme de ce script.

↑ Retour à la liste des actions

Écrire dans une variable PRO

Donnez une valeur à une variable, ou ajoutez-y un nombre — compteurs, totaux cumulés, texte à retenir.

  1. Appuyez sur « Ajouter une action », choisissez Écrire dans une variable
  2. Nommez la nouvelle variable, appuyez sur « Ajouter la variable »
  3. Faites ajouter 1 à la variable
  4. Ajoutez Coller du texte dans le chat : « Message #» + la variable
  5. Ajoutez une étape Appuyer sur « Envoyer »
  6. Répétez le script 3 fois
  7. Appuyez sur Tester, puis ouvrez l’appli

▶ À chaque tour le nombre augmente : 1, 2, 3

Astuces
  • Insérez {nom} dans n’importe quel champ de texte pour utiliser la valeur.
  • Les variables ne vivent que le temps d’une exécution : appuyez sur Arrêter et elles repartent à zéro.
